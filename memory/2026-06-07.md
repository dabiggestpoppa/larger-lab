## 🔴 ROOT CAUSE FOUND: Trigger Reclassification Bug (21:28 EDT)

### What MAD Sent

- Full transcript of OC2/Arch/MAD conversation from June 3

### The Bug
In `symmetry_trap.py`, `_classify_tier_by_impulse()` was updating `self.trigger_pips`
when reclassifying tier based on impulse size. This meant:
1. Session starts with T1 trigger (e.g., 12p for EURUSD)
2. First impulse detected at 25p → reclassified as T2 → trigger becomes 15p
3. Next loop iteration now requires 15p impulse instead of 12p
4. Subsequent loops have HIGHER threshold → fewer trades

### The Fix
- Tier reclassification now ONLY updates `self.au_pips` (for DZ calculation)
- `self.trigger_pips` stays at T1's value for ALL loop iterations
- EURUSD validation: 5,850 trades vs 5,593 baseline = **+4.6%** ✅
