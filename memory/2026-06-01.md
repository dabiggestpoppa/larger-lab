### v1 Deployment (~10:39 AM)
- Deployed first live version with basic signal generation
- **Result: DISASTER** — 0% WR (0W/30L, -393.1p)

- P90 TP1=25% AR, TP2=50% AR ladder
- Up to 5 ST loops per session

- Per-symbol state machine objects (SymbolState class)

## 11:55 AM: cascade_bypass Fix (v2.1.1)
- MAD asked to verify trade count parity between live engine and backtest
- Did formal code-level diff of cerebus_live.py vs quant-lab/engines/symmetry_trap.py
- Found 1 difference: cascade_bypass missing from live engine
- cascade_bypass: P90 exit sets cascade_bias direction, ST loop 2+ can use shallow pullback when bias matches
- Without it: ST loop 2+ waits for full 20-50% Goldilocks on every retry
- With it: captures trades that would otherwise skip in choppy conditions
- Also added: cascade_bias attribute, loop_start_time attribute
- Patched live engine, restarted at 11:55 AM (PID 8068)
- All other logic verified IDENTICAL (triggers, OCC, SL, TP, kill switch, tiers, time rules)
- Trade count parity: RESTORED

- Every code path in live must match backtest exactly to preserve trade count
- Going forward: always diff live vs backtest before declaring parity
