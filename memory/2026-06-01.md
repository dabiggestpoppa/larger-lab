### Deployment Lessons
1. Always initialize session state from historical bars on startup — never rely on a specific hour trigger
2. Close-only SL invalidation is critical — wick-based caused 0% WR in v1
3. State machine parity between backtest and live is non-negotiable
4. Duplicate process detection — always verify single instance
5. Verify session init in deployment logs before declaring success
6. Memory flush can restrict file writes — use Python scripts via exec as fallback
