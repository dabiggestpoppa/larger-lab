## Key Technical Findings

### MT5 vs Pine Script Entry Difference
- MT5 EA uses **market orders** (`ORDER_TYPE_BUY/SELL` with `TRADE_ACTION_DEAL`)
- Pine Script uses **limit orders** (`strategy.entry(..., limit=dmr_deep_state)`)
- MT5 Strategy Tester uses tick data for fills; Pine Script uses OHLC bars only
- This is the PRIMARY reason for WR discrepancy (94% vs 1.85%)
