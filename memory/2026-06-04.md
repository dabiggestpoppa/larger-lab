## Bridge Position Handling Fix (13:30 EDT)

**MAD Directive:** No blocking signals. Backtest has 1:1 parity — engine holds ONE position at a time.

**How backtest handles it:**
- IN_TRADE state → SEARCH block SKIPPED entirely. No new impulse detection.
- On TP/SL hit → `_reset_state_keep_loop()`: state=SEARCH, loop_count++, entry/sl/tp=None
- Next bar after exit → new impulse from exit_price. Can be any direction.
- Close and entry are NEVER on same bar. Close on bar N, next entry bar N+1 or later.

**Bridge fix (1:1 parity):**
- When ENTRY fires on symbol with existing MT5 position → close old position first, then enter new
- This mirrors backtest: exit → reset → next entry (just adapted for MT5 external tracking)
- `symbols_with_positions` gate REMOVED — no ever blocking
- All signals fire always. Old positions close first if present.
