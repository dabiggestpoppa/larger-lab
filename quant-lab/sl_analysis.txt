# Trace ST SL placement for a specific example
# EURUSD: SHORT trade
# OCC candle: high=1.08500, low=1.08400, close=1.08420 (entry for SHORT)
# spread_buffer for EURUSD = 1.5 pips = 0.00015
# min_sl_buffer for EURUSD = 8 pips = 0.00080
# AU = 10 pips = 0.00100

# SHORT trade:
# entry = 1.08420 (OCC close)
# sl = OCC high + spread_buf = 1.08500 + 0.00015 = 1.08515
# min_sl = entry + min_sl_buffer = 1.08420 + 0.00080 = 1.08500
# sl (1.08515) > min_sl (1.08500) → sl = 1.08515 ✓ (above entry, correct for SHORT)
# tp = entry - AU = 1.08420 - 0.00100 = 1.08320 ✓ (below entry, correct for SHORT)

# Distance check:
# SL distance = 1.08515 - 1.08420 = 0.00095 = 9.5 pips
# TP distance = 1.08420 - 1.08320 = 0.00100 = 10.0 pips
# SL is 9.5p, TP is 10p → TP is only 0.5p further than SL!

# LONG trade:
# entry = 1.08500 (OCC close)
# sl = OCC low - spread_buf = 1.08400 - 0.00015 = 1.08385
# min_sl = entry - min_sl_buffer = 1.08500 - 0.00080 = 1.08420
# sl (1.08385) < min_sl (1.08420) → sl = min_sl = 1.08420 ✓ (below entry, correct for LONG)
# tp = entry + AU = 1.08500 + 0.00100 = 1.08600 ✓ (above entry, correct for LONG)

# Distance check:
# SL distance = 1.08500 - 1.08420 = 0.00080 = 8.0 pips
# TP distance = 1.08600 - 1.08500 = 0.00100 = 10.0 pips
# SL is 8p, TP is 10p → TP is only 2p further than SL

print("=== ST SL PLACEMENT ANALYSIS ===")
print()
