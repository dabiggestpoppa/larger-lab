# OLD ENGINE SL ANALYSIS — WITH ACTUAL MATH
# 
# LONG TRADE:
#   Impulse candle: high = 1.08500 (this is impulse_extreme)
#   OCC candle: close = 1.08400 (this is entry)
#   SL = impulse_extreme = 1.08500
#   
#   For LONG: SL check is `bar.close <= self.sl_price`
#   bar.close <= 1.08500
#   Entry is 1.08400
#   
#   So SL (1.08500) is ABOVE entry (1.08400)
#   For a LONG trade, SL should be BELOW entry
#   → SL IS ON THE WRONG SIDE FOR LONG ✗
#   
#   Price would have to go UP to 1.08500 to hit the SL
#   But that's in PROFIT direction for a LONG
#   So the SL can never be hit by a losing trade
#   The trade would TP hit first, or KILL_SWITCH, or EWS_EXIT
#
# SHORT TRADE:
#   Impulse candle: low = 1.08200 (this is impulse_extreme)
#   OCC candle: close = 1.08300 (this is entry)
#   SL = impulse_extreme = 1.08200
#
#   For SHORT: SL check is `bar.close >= self.sl_price`
#   bar.close >= 1.08200
#   Entry is 1.08300
#
#   So SL (1.08200) is BELOW entry (1.08300)
#   For a SHORT trade, SL should be ABOVE entry
#   → SL IS ON THE WRONG SIDE FOR SHORT ✗
#
#   Price would have to go DOWN to 1.08200 to hit the SL
#   But that's in PROFIT direction for a SHORT
#   So the SL can never be hit by a losing trade
#
# CONCLUSION: In the OLD engine, SL was on the WRONG side for BOTH directions
# The impulse extreme is always beyond the entry in the profit direction
# (because the impulse is the big move, and OCC is the pullback confirmation)
#
# This means:
# 1. SL was NEVER hit in the backtest (it was in profit territory)
# 2. Trades only exited via TP_HIT, KILL_SWITCH, or EWS_EXIT
# 3. The 85% WR was REAL in the sense that 85% of exits were TP_HIT
# 4. But it was MISLEADING because losing trades were exited via KILL_SWITCH
#    and counted as neither wins nor losses (or counted as losses but at small size)
#
# Wait — the backtest shows W: 989 L: 171 out of 1163
# So 171 trades WERE counted as losses
# These must be KILL_SWITCH exits with negative pnl
# 
# Let me check: KILL_SWITCH exit uses bar.close as exit_price
# If KILL_SWITCH fires when price pulls back 80% of impulse,
# the exit could be below entry (for LONG) = loss
#
# So the 171 losses are KILL_SWITCH exits
# The 989 wins are TP_HIT exits
# SL_HIT = 0 (because SL was on wrong side, never hit)
#
# This means the old 85% WR was:
# - 85% TP_HIT (real wins)
# - 15% KILL_SWITCH (real losses)
# - 0% SL_HIT (SL never hit because it was on wrong side)
#
# The new engine has SL on correct side (OCC extreme)
# So now trades CAN be stopped out by SL
# This adds a new category of losses that didn't exist before
# Hence WR drops to 44%
#
# BUT — the old MT5 trades had the bridge clamping the SL to correct side
# So MT5 trades WERE getting stopped out by SL
# The backtest was NOT simulating what MT5 was actually doing
#
# The question is: what was the actual MT5 win rate?
# If MT5 was getting SL hits and showing ~44% WR, then the new backtest is correct
# If MT5 was showing 85% WR, then something else is going on
