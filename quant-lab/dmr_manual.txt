   The field resolves conflicting intents through minimal changes (resolution outputs).

   Direction of Constraint Resolution = the orientation of the current resolution process.
   It is not assumed to persist. Each session begins fresh with a new constraint set.

   Strong Subadditivity (SSA): the current state already embeds all past information.
   Adding more indicators does not increase edge ΓÇö it increases noise.
4. BREAKOUTS ARE CONSTRAINT VIOLATIONS
   Resolution occurs when existing constraints cannot contain the state.
   The 132% level is the Kill-Switch State: the constraint set has been violated.

   168% = Stall Zone State (resolution output pausing at a constraint cluster)
   200% = Deep State (extended resolution, often exhaustion)
   132% = Kill-Switch State (invalidation of current constraint set)
6. TRADING IS STATE RECOGNITION, NOT CANDLE PREDICTION
   The Markov Property: the current state contains all necessary information.
   Past data is fully embedded in the present state. Align with the field's resolution.

import pandas as pd
import numpy as np
from sklearn.cluster import KMeans
def discover_atomic_units(csv_path, pip_size=0.0001):
    df = pd.read_csv(csv_path, header=None,
                     names=['dt','open','high','low','close','vol','spread','ts'])
    df['dt'] = pd.to_datetime(df['dt'])
    df = df.set_index('dt').sort_index()
    if df.index.tz is None:
        df = df.tz_localize('UTC').tz_convert('America/New_York')
    else:
        df = df.tz_convert('America/New_York')
    df['session'] = (df.index - pd.Timedelta(hours=3)).dt.floor('D')
    ranges = []
    for day, data in df.groupby('session'):
        asian = data[(data.index.hour >= 19) | (data.index.hour < 3)]
        if len(asian) >= 10:
            ar = (asian['high'].max() - asian['low'].min()) / pip_size
            ranges.append(ar)
    ranges = np.array(ranges).reshape(-1, 1)
    km = KMeans(n_clusters=3, random_state=42, n_init=10).fit(ranges)
    centroids = sorted(km.cluster_centers_.flatten())
    cutoff1 = (centroids[0] + centroids[1]) / 2
    cutoff2 = (centroids[1] + centroids[2]) / 2
    results = {
        'T1': {'range_max': cutoff1, 'centroid': centroids[0],
               'atomic_unit': int(centroids[0] * 0.50),
               'trigger': int(centroids[0] * 0.50 * 1.2)},
        'T2': {'range_min': cutoff1, 'range_max': cutoff2, 'centroid': centroids[1],
               'atomic_unit': int(centroids[1] * 0.50),
               'trigger': int(centroids[1] * 0.50 * 1.2)},
        'T3': {'range_min': cutoff2, 'centroid': centroids[2],
               'atomic_unit': int(centroids[2] * 0.50),
               'trigger': int(centroids[2] * 0.50 * 1.2)}
    }
    return results
# USAGE: discover_atomic_units('EURUSD_M5.csv', pip_size=0.0001)
