CORE OPERATING PRINCIPLES
CONSTRAINT LOGIC — SIX OPERATING PRINCIPLES
IIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIIII
1. THE FIELD IS NOT A BATTLEGROUND
   The field resolves conflicting intents through minimal changes (resolution outputs).
   There are no "buyers" or "sellers" — only constraint states being resolved.
2. NO INHERENT DIRECTION
   Direction of Constraint Resolution = the orientation of the current resolution process.
   It is not assumed to persist. Each session begins fresh with a new constraint set.
3. INDICATORS DO NOT CREATE INFORMATION
   Strong Subadditivity (SSA): the current state already embeds all past information.
   Adding more indicators does not increase edge — it increases noise.
4. BREAKOUTS ARE CONSTRAINT VIOLATIONS
   Resolution occurs when existing constraints cannot contain the state.
   The 132% level is the Kill-Switch State: the constraint set has been violated.
5. FIBONACCI LEVELS ARE STATES, NOT TARGETS
   168% = Stall Zone State (resolution output pausing at a constraint cluster)
   200% = Deep State (extended resolution, often exhaustion)
   132% = Kill-Switch State (invalidation of current constraint set)
6. TRADING IS STATE RECOGNITION, NOT CANDLE PREDICTION
   The Markov Property: the current state contains all necessary information.
   Past data is fully embedded in the present state. Align with the field's resolution.

Full footnote reference — these definitions apply throughout all Parts:
[1] Field

[2] Resolution Output
Replaces 'price.' The numeric output printed when the field resolves a constraint. Not an intrinsic value or an opinion — it is the minimal
change required.
[3] Direction of Constraint Resolution
Replaces 'trend.' The current orientation of the field's resolution process. Describes how the field is rebalancing constraints, not a
persistent direction.
[4] Available Resolution Pathways
Replaces 'liquidity.' The accessible channels through which the field resolves constraints. 'Liquidity grabs' become 'available resolution
pathway harvesting.'
[5] Constraint Violation

Replaces 'breakout.' A sudden change when the field's constraints are exceeded. Not random — required when the field can no longer

[6] Partial Rebalancing
Replaces 'pullback.' Temporary adjustment after a strong movement. Indicates short-term resolution of an imbalance, not a reversal
signal.
[7] Resolution Output Stall
Replaces 'stall.' A period when the field temporarily stops advancing because it is processing a local constraint cluster. The
Stall-Harvest Trading System focuses on this phase.
[8] Constraint Boundary
Replaces 'stop' or 'stop-loss.' A state at which the current constraint set is invalidated. Not arbitrary — represents the limit beyond which

activation signal.
[10] Fib Extension States
168%, 200%, 132% are not entries or stops. They are states describing how far the resolution output has extended. 168% = stall state;
200% = deep state; 132% = kill-switch state.

[12] Strong Subadditivity (SSA)

[13] Markov Property

context does not add predictive power.
