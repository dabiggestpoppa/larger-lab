# 0. Program shape

CSIA is planned as **10 Books**.

Each Book defines one coherent system concern.

Books contain **Blocs**.

Blocs contain **Chapters / checkpoints**.

```text
BOOK
  -> BLOC
       -> CHAPTER
            -> CONTRACT
            -> TEST
            -> EVIDENCE
            -> EXIT GATE
```

The Books are:

```text
BOOK 0  Constitution, Epistemics, and Program Governance
BOOK 1  Identity, Ontology, and Temporal Knowledge Graph
BOOK 2  Source Fabric, Evidence, and Research Acquisition
BOOK 3  Native Chain / Ledger Atlas
BOOK 4  Protocol, Infrastructure, and Dependency Atlas
BOOK 5  Capital Plumbing and Economic Topology
BOOK 6  Fundamental Measurement and State Modeling
BOOK 7  Narrative, Events, and Ecosystem Evolution
BOOK 8  Crypto Sensor Context Bridge
BOOK 9  Operator Intelligence Surfaces and Continuous Research
```
