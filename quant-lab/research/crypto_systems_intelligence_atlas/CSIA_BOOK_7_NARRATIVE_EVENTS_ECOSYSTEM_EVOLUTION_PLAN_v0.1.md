## 0. Goal and constitutional posture

Connect what the market is talking about to what actually changes — as
**descriptive linkage**, never as truth creation. Book 7 records that stories
circulate, that events occurred (on evidence), that actions were declared and
deployed (per owning books), and that responses were measured (per Books 5/6) —
and it never lets the story stand in for the world (Axiom 3; §20–21; §5.3a; §25).

## 2. Bloc 7A — Event ontology

- **Grammar:** six-way separation `EVENT != CLAIM != NARRATIVE != ACTION != STATE CHANGE != EVIDENCE` (Event Grammar §1).
- **Contracts (planned):** EventIdentity, EventOccurrence, EventClaimLink, EventObjectImpact, EventStatus, EventTemporalWindow, EventEvidenceBinding; plus EventSeries for recurrence and staged programs.
- **Identity:** `REPORT_COUNT != EVENT_COUNT`; identity key `(subject_scope, event_family, occurrence_signature, temporal_anchor)`; contested identity preserved; multi-stage programs = series with per-stage events (identity doctrine finalization = D7N-1).
- **Families:** 8 KEEP (UPGRADE, INTEGRATION, MIGRATION, EXPLOIT, OUTAGE, GOVERNANCE, REGULATORY_EVENT, TOKENOMICS_CHANGE) + 4 REVISE (LAUNCH→refold, INSTITUTIONAL_ADOPTION→actor_class attribute, BRIDGE_CHANGE/STABLECOIN_CHANGE→subject_class attributes) + venue/LISTING deferred to the market seam; mechanism classes, not news sections (Event Candidate Matrix).
- **Lifecycle:** REPORTED→DECLARED→CONFIRMED_OCCURRENCE→ONGOING→RESOLVED / REVERSED / SUPERSEDED / CONTESTED / UNKNOWN — occurrence history, never a duplicate of Book 2 ClaimState (AB-2).
- **Temporality:** ten-field model (7 event fields + inherited bitemporal axes); report time != event time != effective time != observation time; family subsets; no fabricated dates.
- **Structural seam:** `EVENT SAYS CHANGE OCCURRED != BOOK 7 WRITES THE STRUCTURAL FACT` — CHANGED / CHANGE_CLAIMED / NO_CHANGE_FOUND / NOT_APPLICABLE, reference-only (AB-1).
- **Family evidence bars:** security (REPORT≠INCIDENT; loss claims separate), governance (proposal≠vote≠execution≠activation), regulatory (jurisdiction + stage + effective_at), institutional (announcement≠adoption), tokenomics (proposal≠executed change).

## 3. Bloc 7B — Narrative objects

- **Grammar:** NARRATIVE / NARRATIVE CLAIM / MESSAGE / SOURCE UTTERANCE / THEME / THESIS / EVENT — seven non-collapsible terms (Narrative Model §1).
- **Identity:** `(narrative_core, subject_scope, temporal_lineage)`; split/merge/relapse recorded with lineage; same-narrative vs related vs contradicted resolved by core, not keywords (methodology = D7N-2).
- **Origin/propagation:** descriptive only — origin (may be UNKNOWN), earliest observation, typed propagating sources, amplification milestones, cross-community/institutional propagation, first-party adoption as a distinct relation, propagation epochs for reappearance. **Zero scores** (no influence/truth/investment/virality) — AB-3.
- **Evidence firewall:** E4 establishes existence/utterance/circulation only; FW-1..FW-4 make `NARRATIVE EXISTENCE != NARRATIVE CLAIM TRUTH` and §20.1 mechanically enforceable (type-level, like Book 6's anti-score firewall).
- **Contradiction:** seven typed forms; both lines preserved; never averaged; resolution arrives only as new Book 2/owning-book evidence, recorded by reference.
- **State governance:** `STATE NAME != DERIVATION RULE` (the Book 6 lesson); three-class doctrine (A available, B post-ratification, C deferred); **zero narrative-state rules ratified**; Book 7-specific contract recommended, not Book 6 code/authority (D7N-3).

## 4. Bloc 7C — Narrative-to-action

- **Ladder (constitutional §21):** CLAIM → DECLARED ACTION → DEPLOYED ACTION → USAGE RESPONSE → CAPITAL RESPONSE → MARKET_RESPONSE_REF.
- **Arrows are linked observations, not causation**; ladders stop at any rung legitimately; every rung independently evidence-bound.
- **DECLARED ≠ EXECUTED ≠ USED** (D2-6 full length); DEPLOYED requires Book 2-backed structural truth via owning books — never from announcement/press/roadmap/social (§20.1, D2-5 spirit).
- **USAGE RESPONSE:** Book 6 refs only; no thresholds, no health, no missingness override (`USAGE RESPONSE OBSERVED != USAGE HEALTH`).
- **CAPITAL RESPONSE:** Book 5/6 refs only; timeline linkage is Book 7's product; no topology rewrite.
- **MARKET RESPONSE:** `MARKET_RESPONSE_REF` only — the Book 8 seam ceiling (D7N-5); no regime semantics, no combined confirmation states, no lag windows, no D8.
- **Causality:** four levels — TEMPORAL ORDER != ASSOCIATION != MECHANISTIC LINK != CAUSAL CLAIM; "after" permitted, "caused" reserved for ratified event-study methodology (D7N-4); `causal_status` closed vocabulary with Level 4 unreachable.
- **Link contract:** NarrativeActionLink (stressed field set; optional stages legitimate); **response absence** six states — NO_RESPONSE_OBSERVED / RESPONSE_NOT_MEASURED / RESPONSE_DATA_UNAVAILABLE / TOO_EARLY_TO_ASSESS / NOT_APPLICABLE / UNKNOWN — absence is never failure, never zero.
- **Lag/windows:** no universal numerals (24h/7d/30d/90d rejected); family-typed `ResponseWindowMethodology` with explicit inputs; every window cites its methodology ref; Book 8 may own market-specific alignment later.

## 5. Bloc 7D — Ecosystem evolution

- **Diff objects:** GraphDiff, NodeChange, EdgeChange, DependencyChange, MigrationChange, TopologySnapshotDiff — between **accepted** states only, reproducible, reference-justified.
- **Semantics:** nine row types; **graph change != good/bad**; every new edge is not growth; ROLE_CHANGED/MIGRATED resolve through Book 3 identity.
- **Migrations:** `MIGRATION EVENT != NEW OBJECT AUTOMATICALLY`; origin/destination/continuity/partial/dual-running/rollback/completion tracked via Book 3 lineage (D3-1/D3-2/D3-7); no identity invention.
- **Dependency gain/loss:** described via Book 4 records; no Book 4 facts minted; unresolvable claims stay CHANGE_CLAIMED.
- **Expansion/contraction:** generic EXPANSION/CONTRACTION **rejected** as an unqualified scalar; dimension-specific evolution states only (object count, integration count, economic-function coverage, capital routes, active deployments), each rule-gated; no universal ecosystem-size scalar (§5.3a).
- **Historical replay:** `PRESERVED_GRAPH_HISTORY != REVALIDATED_HISTORICAL_TOPOLOGY`; replay machinery diffs only what upstream accepted records preserve; unreconstructable = NOT_SUPPORTED, never backfilled (D7N-6).
- **Bitemporality:** valid / observation / source / revision time on every consequential object; late discovery enters transaction-time late; history never rewritten.
