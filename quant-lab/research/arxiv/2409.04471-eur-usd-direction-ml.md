# Paper Summary: Predicting Foreign Exchange EUR/USD Direction Using Machine Learning

**arXiv:** 2409.04471 | **Published:** Sep 2024 | **Author:** Kevin Guyard

## Overview
Comparative analysis of ML models for predicting daily directional movement of EUR/USD.

## Core Strategy Logic
- Predict next-day direction (up/down) of EUR/USD using supervised ML classifiers
- Use both decorrelated and non-decorrelated feature sets via PCA
- Employ **meta-estimators (stacking)**: multiple base estimators feed into a meta-estimator for final prediction
- Features: technical indicators (moving averages, RSI, MACD, Bollinger Bands, etc.)
- PCA used for dimensionality reduction and decorrelation

## Reported Performance
- **Prediction accuracy:** 58.52% (one-day ahead)
- **Annual return:** 32.48% (year 2022)
- Better than random (50%) and most single-model approaches

## Features/Indicators Used
- Standard technical indicators (MA, EMA, RSI, MACD, Bollinger Bands)
- PCA-transformed feature sets
- Stacking ensemble of multiple classifiers

## Key Insight
Stacking ensemble + PCA decorrelation provides edge over individual models. The 58.52% directional accuracy may seem modest, but with proper risk management (asymmetric payoffs), it translates to significant returns.

## Implementation Notes for Quant Lab
- Could be adapted as a daily directional bias filter for intraday strategies
- The stacking approach suggests combining multiple weak signals → aligns with RohOnChain's alpha combination framework
- Could use as a regime classifier: >55% accuracy = trend-following mode, <45% = mean-reversion mode
