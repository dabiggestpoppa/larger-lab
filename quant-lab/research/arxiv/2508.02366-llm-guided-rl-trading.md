# Paper Summary: Language Model Guided Reinforcement Learning in Quantitative Trading

**arXiv:** 2508.02366 | **Published:** Aug 2025 | **Author:** Adam Darmanin | **Accepted:** FLLM 2025, Vienna

## Overview
Hybrid framework where LLMs generate high-level trading strategies to guide RL agents, combining strategic reasoning with tactical execution.

## Core Strategy Logic
- **LLM layer:** Generates high-level trading strategies via structured prompts
  - Provides strategic reasoning and multi-modal signal interpretation
  - Acts as a "portfolio manager" giving directional bias and risk guidance
- **RL agent layer:** Executes trades based on LLM guidance + market state
  - Handles short-term tactical decisions
  - Optimizes entry/exit timing and position sizing
- **Evaluation:** LLM strategies reviewed by experts for economic rationale
- **Comparison:** LLM-guided agents vs unguided RL baselines

## Reported Performance
- LLM guidance **improves both return and risk metrics** vs standard RL
- Higher **Sharpe Ratio** than unguided RL
- Lower **Maximum Drawdown** than unguided RL
- Expert review confirms economic rationale of LLM-generated strategies

## Features/Indicators Used
- LLM processes: market context, news, technical levels, macro environment
- RL agent processes: price action, position state, PnL
- Combined state space: LLM strategy + market features

## Key Insight
The LLM provides the "why" (strategic reasoning) while the RL provides the "how" (tactical execution). This separation of concerns produces more robust strategies than either approach alone.

## Implementation Notes for Quant Lab
- Simplified version: use LLM-generated daily bias as a filter for existing strategies
- The LLM could analyze market context and output: {regime: trending/mean-reverting, bias: bullish/bearish, confidence: 0-1}
- RL component could be simplified to rule-based execution with LLM-adjusted parameters
