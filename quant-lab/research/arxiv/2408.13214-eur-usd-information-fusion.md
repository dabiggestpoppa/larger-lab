# Paper Summary: EUR/USD Exchange Rate Forecasting Based on Information Fusion with LLMs and Deep Learning

**arXiv:** 2408.13214 | **Published:** Aug 2024 | **Author:** Hongcheng Ding

## Overview
Novel framework "IUS" integrating unstructured textual data (news, analysis) with structured financial data for EUR/USD prediction.

## Core Strategy Logic
- **Data fusion:** Combine two data sources:
  1. **Unstructured:** News articles, market analysis texts → processed via LLM for sentiment polarity scoring and exchange rate movement classification
  2. **Structured:** Exchange rates, financial indicators (interest rate differentials, economic indicators)
- **Feature engineering:** Causality-Driven Feature Generator combines both feature types
- **Model:** Optuna-optimized Bi-LSTM (bidirectional LSTM with hyperparameter optimization)
- **Feature selection:** Top 12 quantitative features + textual features = best performance

## Reported Performance
- **MAE reduction:** 10.69% vs best baseline
- **RMSE reduction:** 9.56% vs best baseline
- Outperforms SVM, SVR, ARIMA, GARCH baselines
- Textual + structured data together > structured data alone

## Features/Indicators Used
- Sentiment polarity scores from news (via RoBERTa-Large / LLM)
- Topic modeling features (LDA)
- Causality-driven derived features
- Top 12 quantitative features (exchange rate history, financial indicators)
- Optuna-optimized Bi-LSTM hyperparameters

## Key Insight
Multi-source data integration (text + quantitative) consistently beats quantitative-only models. The news sentiment component provides a "leading indicator" signal that price data alone misses.

## Implementation Notes for Quant Lab
- Simplified version: use news sentiment as a directional bias filter
- For forex: central bank speech sentiment, NFP/cPI surprise sentiment could be manually coded
- The Bi-LSTM component could be a standalone price-prediction model
