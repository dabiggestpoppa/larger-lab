## 2. Sampling design (continuous, PIT-safe)

The LF5 peer maps are event-anchored (each asset-day that was an isolated
>= 2 sigma move carries a membership snapshot). LF9 does NOT re-derive daily
behavioral/correlation peer maps (that would reinvent LF5). Instead the
relational-state object is carried forward PIT-safely:

- For every asset-day on the LF5 substrate where the asset has had at least
  one peer snapshot at or before that day, the most recent snapshot's
  relational state (and its membership metrics, loner label, and regime
  forward-outcome flags) is the asset's state for that day.
- Days before the asset's first snapshot are NO_COVERAGE (state unsupported,
  never forced).
- `days_since_snapshot` and a freshness class are carried on every row, so
  stale carry days can be excluded or conditioned on. Coverage/quality flags
  (stale price, zero volume, any quality flag) come from the LF5 substrate.
- The MECH-15 global field surface (16-cell exact construction from the
  cached daily field frame, plus the 6-cell candidate and 8-cell research
  reference from the merge tree) is joined by date.

This is the honest continuous reading of the frozen PIT substrate: state is
*defined* at snapshots and *persists* between them until re-derived. All
state assignments use t0 and asset-past only.

## 3. Key hypotheses (falsifiable, descriptive)

- **H1 — Relational-state persistence survives continuous sampling.** On the
  exact-calendar continuous panel, relational-state persistence at 1/3/7/14/
  30/60D remains above same-member persistence. Conditional-on-new-snapshot
  (the LF8 analogue) is reported alongside unconditional persistence so the
  comparison is honest. If continuous persistence collapses to the membership
  level, LF8 is corrected.
- **H2 — Topology rewires fast while role stays slow.** Membership Jaccard /
  entropy move fast; relational-state survival and role transition entropy
  stay low-change. Allowed: TOPOLOGY_FAST_ROLE_SLOW / BOTH_FAST / BOTH_SLOW /
  STATE_DEPENDENT.
- **H3 — Physical shock still precedes local reorganization.** On the
  continuous panel, ABS shock (T0) precedes membership turnover (T1),
  relational-state change (T2), and contagion/rejoin/decoupling (T3) more
  often than the reverse; median lags reported with bootstrap CIs. Causal
  claim capped at L2.
- **H4 — Sigma remains secondary to absolute disturbance.** In the 2D
  abs x sigma grid, turnover / decoupling / state-change respond to absolute
  class; sigma class adds little within abs class.
- **H5 — Volume is a reorganization coordinate, not just a shock carrier.**
  Volume amplitude adds incremental purged-AUC / partial correlation over
  absolute return. Allowed: INDEPENDENT_REORGANIZATION_COORDINATE /
  SHOCK_CARRIER / REDUNDANT / LOCAL_ONLY.
- **H6 — Global field modulates the local shock response.** For matched shock
  amplitude, turnover / decoupling / contagion response differs across global
  field cells (6-cell candidate and 8-cell reference). Allowed:
  FIELD_MODULATED_LOCAL_RESPONSE / LOCAL_RESPONSE_INVARIANT /
  STATE_LOCAL_ONLY / DATA_LIMITED. Relational state is NOT placed in the core
  global matrix.
- **H7 — EARLY_CONTAGION / PERSISTENT_DECOUPLING survive validation.**
  Both true-loner subtypes must survive chronological split, leave-one-cycle-
  out, and BH-FDR across the subtype scan, or they are demoted.
- **H8 — The false-loner artifact is a low-vol normalization artifact.**
  Re-tested on the continuous panel with physical amplitude + local peer
  context; if LOW_VOL_NORMALIZATION_ARTIFACT still dominates, the LF8 finding
  stands.
- **H9 — Downside/upside contagion asymmetry is robust.** Downside contagion
  ~0.346 vs upside ~0.143 (LF8). Replicated across cycles / rank depth /
  field cells / shock bands / relational states. Allowed:
  ROBUST_SIGN_ASYMMETRY / FIELD_CONDITIONAL_ASYMMETRY / RANK_LOCAL_ASYMMETRY /
  NO_STABLE_ASYMMETRY.
- **H10 — PRD relational-health subtypes survive.** RELATIVE_DECAY /
  TEMPORARY_SPLIT revalidated (purged, FDR, cycles, field overlay):
  PROMOTE / LOCAL / MERGE / DISSOLVE per subtype. Rescue subtypes are not
  resurrected without support.
- **H11 — Predictive null freeze.** ONE final robustness audit of relational
  state vs exact peer identity / best-other for recovery / contagion /
  decoupling. If relational state still has no incremental information:
  FREEZE NULL — RELATIONAL_STATE_NOT_INCREMENTAL_PREDICTOR — and stop testing

- **H12 — Descriptive hierarchy is coherent.** GLOBAL FIELD -> RANK PATCH ->
