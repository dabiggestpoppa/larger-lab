# LOWER-FIELD-4 SUMMARY

LF4 was designed to replace same-band isolation with true PIT peer geometry. The available LF2 cache supports a valid same-date rank-neighbor map (±25/±50/±100), but it does not contain a complete historical feature matrix or trailing-return matrix for behavioral and correlation nearest neighbors. Those families are therefore DATA_BLOCKED, not silently approximated.

The reproducible event universe contains 1,023 primary isolated downside observations at |z1|>=2 in the LF3 event table. Rank-context isolation is a valid descriptive coordinate. It cannot establish whether a supposed loner is a true behavioral loner, whether peers catch down, or whether the asset rebounds toward peers.

LF2/LF3 reversal geometry remains a parent finding: isolated downside events show sign- and depth-dependent forward reversal patterns. LF4 does not overclaim peer attribution because the required peer maps are unavailable. Price-recovery versus rank-health clocks are DATA_BLOCKED: the cache provides pre-event rank velocity, not future rank observations.

The LF3 basket dispersion anomaly is not reused. LF4 rebuilds dispersion from finite same-date raw returns, and the triangle output is relabeled as Pearson correlations and residual variance ratios; prior near-one unlabeled values are not treated as conditional probabilities.

Volume/active-liquidity and HH anatomy are descriptive only without the requested joint purged models. SHHM versus SHMC receives one focused descriptive recheck. No strategy, PnL, directional signal, execution, or deployment claim is made.
