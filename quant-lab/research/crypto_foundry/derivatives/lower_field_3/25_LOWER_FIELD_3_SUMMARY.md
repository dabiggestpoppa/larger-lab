# LOWER-FIELD-3 SUMMARY

LF3 moves from endpoint reversal rates to local event anatomy while preserving the LF2 integrity repair and its restrictions.

## Main findings

- A contextual lonely dump is a same-band >=2-sigma downside event with exactly one same-sign >=2-sigma mover in that band/date. Rank-window neighbors are computed with a causal same-date PIT join. Behavioral, correlation, and state neighborhoods remain schema-reserved because no validated fixed peer map is present in LF2. No master isolation score was invented.
- Isolated 3-sigma downside events are disproportionately temporary shocks: the path map shows stronger 7D reversal/recovery than coordinated events. Deepest isolated cells are thin, so this is a LOCAL_NODE, not a universal rule.
- Coordinated upside events (`BAND_BROAD_UP`/`MULTI_BAND_UP`) are synchronized and tend toward giveback; continuation/exhaustion divergence is descriptive only.
- The reversal state machine makes 1-sigma recovery explicit. Recovery, 25/50-percent giveback, full reversal, and new-extreme states are competing event-time observations, not a sequential signal.
- The LF2 SHMC correction survives: `SHORT_HOT_MEDIUM_HOT` has higher normalized tail probability than SHMC. SHMC-specific activation is dissolved; medium-horizon alignment is a continuation/reversion geometry candidate only.
- Rank deterioration is retained as a queued rank-health bridge; no death/extinction label is assigned.
- `BRD_HI + DISP_HI` is the repeated local state with >=50 effective observations and >=3 periods. It raises next-day tail-delivery activity and is consistent with the LF2 breadth gate.
- The basket implementation is descriptive cohort geometry only. The triangle pilot treats A=Top-500 breadth, B=lower dispersion, C=tail share as one higher-order dependency; no universal mediation claim is made.

## Interpretation

The lower field changes form with participation: isolated downside shocks are local and rebound-prone, whereas coordinated upside is broad and giveback-prone. This is a participation-topology node, not a trading instruction. Center coupling and tail localization from LF1/LF2 remain intact.

## Limits

MECH-7 was available in the repository but was not consumed by LF3 core generation; the output schema preserves a date-keyed join path so context can be attached later without regenerating core events. Formal behavioral/correlation neighbor maps, 60D censoring, stable trajectory clustering, and execution/tradability audits are not earned. All claims are L0, except breadth-to-delivery as an L1/L2 candidate.
