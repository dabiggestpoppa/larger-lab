# LOWER-FIELD-5 PREREGISTRATION

LF5 has a hard two-stage gate. Stage A builds a reusable PIT asset-date feature substrate and causal return histories. Stage B may run true behavioral/correlation/state peer analysis only if Stage A passes integrity.

Primary universe: PIT ranks 501–2000; comparison ranks 26–500 only where repaired source coverage permits. Features are calculated on continuous per-asset histories before rank-band filtering. Missing observations remain missing; no survivor backprojection, zero-fill, future listing information, or outcome-based peer definition.

Peer families are frozen: rank ±25/50/100; behavioral top 5/10/20 from standardized pre-event rank, market cap, volume/turnover, age, trailing volatility, ret7, ret30; correlation top 5/10/20 from causal trailing 60D/120D correlations with minimum overlap; state peers; and a hybrid local basket. No k is selected on outcomes.

Validation requires coverage, missingness, membership turnover/Jaccard stability, pre-event similarity, next-window out-of-sample similarity, basket correlation, and cycle/depth stability. A family is VALID only if it improves future similarity over random same-band peers without outcome leakage.

Primary events use LF2/LF3 causal z1 with >=2σ and >=3σ downside/upside lenses. All isolation coordinates remain separate. Named classes/sequences require >=50 effective events and >=3 subperiods. BH-FDR and asset/event purging are required for broad inference.

Recovery anchor is the event low when available; otherwise event close/shock anchor. Recovery means positive movement opposite the event direction, normalized by pre-event sigma. Future rank health is measured separately. Causality is capped at L0/L1 unless strictly lagged, common-factor-robust evidence earns more.

If any critical Stage-A integrity check fails, Stage B stops and decision is DATA_BLOCKED. No strategy, PnL, execution, sizing, leverage, or deployment work is permitted.
