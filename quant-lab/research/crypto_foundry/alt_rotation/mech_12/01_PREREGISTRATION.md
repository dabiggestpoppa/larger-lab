## 1. Purpose

MECH-12 deepens the field from **STATE + CLOCKS** into **FULL STATE LIFECYCLE +
ALLOWABLE SEQUENCES + BRANCHING CONSTRAINTS**. The core question:

> For each local field state, what are the valid birth conditions, survival
> conditions, perturbation responses, transition routes, failure routes, and
> terminal/resolution branches?

Direction remains SECOND ORDER. We do not optimize up/down. We search broadly,
then let the data narrow the valid primitive set.

## 3. Workstreams and pre-committed tests

1. **WS1 — FULL 4-STATE LIFECYCLE** (02). Per cell x age band, horizons
   1/2/3/5/7/10/14/21/30: P(stay), P(exit), P(reentry), P(propagate),
   P(tail activation), P(rank recruitment), P(transition to each cell),
   P(local stress), P(local recovery). Pre-committed: each cell has its own
   mass-migration law (HH back-loads propagation; HL decays with age; LL is
   dormant; LH is a transient corridor).

2. **WS2 — FAILURE GEOMETRY PER STATE** (03). For each state, compare the
   success path vs its failure mirror. Classify divergence as
   DIFFERENT_AT_BIRTH / DIVERGES_EARLY / DIVERGES_LATE / NO_STABLE_SEPARATION
   using t0, +1, +3, +7 coordinates.

3. **WS3 — BROAD SEQUENCE SEARCH** (04). Symbolic-dynamics words over 17
   atoms (breadth expand/contract, concentration release/rebuild, dispersion
   expand/contract, tail up/down activate, rank recruit/decay, vol
   expand/contract, stablecoin up, TVL velocity up, state exit/reentry,
   propagation confirms) across rolling windows 1/2/3/5/7/10/14D. Sequences
   named COMMON / LOCAL / RARE / NULL per >=50 / >=3 subperiods / FDR.

4. **WS4 — PARTIAL-ORDER CONSTRAINT GRAPH** (05, 06). For every atom pair,
   P(A before B | both), P(B before A | both), P(same window), n. Edge
   classes REQUIRED_ORDER / PREFERRED_ORDER / EXCHANGEABLE / NO_ORDER /
   INCONCLUSIVE. Cycles preserved — no DAG forcing.

5. **WS5/6 — PREFIX BRANCHING + CONSTRAINT-RESOLUTION ENTROPY** (07, 08).
   Shannon entropy of next-event branch distribution by state, age, sequence
   depth, perturbation amplitude. Verdict ENTROPY_COLLAPSE /
   LOCAL_ENTROPY_COLLAPSE / NO_STABLE_COLLAPSE / INCONCLUSIVE.

6. **WS7 — WATERFALL AS THRESHOLD HIERARCHY** (09). Field intensity at FIRST
   activation for each rank band: breadth, dispersion, vol, BTC return,
   stablecoin activity, TVL velocity, tail share, concentration. Test whether
   deeper bands require stronger common-field intensity.

7. **WS8 — RANK-PATCH GRAPH** (10, 11). Node attrs (internal coherence,
   false-loner density, tail share, reversal rate, median shock amplitude,
   dispersion, rank migration, state occupancy, activation threshold) and
   edge attrs (same-day synchrony, lagged association) between patches.

8. **WS9 — LOCAL PATCH RESPONSE TO PERTURBATION** (12). Patch x perturbation
   type (breadth jump/drop, dispersion jump/drop, BTC shock, vol shock,
   concentration release) x amplitude (SMALL/MEDIUM/LARGE): activation
   probability, tail share, rank velocity, recovery latency.

9. **WS10 — PEER-FORMATION CONTEXT** (13). Join LF6 peer-rejoin/catchdown
   event data to field context (state, age, vol, BTC, breadth, dispersion,
   stablecoin, TVL). High vs low peer-reorganization conditions.

10. **WS11 — METASTABILITY LIGHT AUDIT** (14). Dwell, return probability,
    escape probability, transition flux, recurrence, local stationary share
    per cell. Verdict METASTABLE_LIKE / TRANSIT_CORRIDOR / ORDINARY_STATE /
    INCONCLUSIVE.

11. **WS12 — TRANSFER-FLOW PILOT** (15). Only if WS11 earns metastability-like
    structure: dominant probability-flow channels. Otherwise documented as
    not earned.

12. **WS13 — LONER FIELD PLACEMENT** (16). LF6 consensus loner classes placed
    across state, age, rank patch, sequence position, perturbation amplitude,
    constraint entropy.

13. **WS14 — ABSOLUTE vs SIGMA AMPLITUDE** (17). 2D bins z_sigma x absolute
    return (and mcap-change where valid): separate explanatory roles.

14. **WS15 — UP vs DOWN FIELD ASYMMETRY** (18). Field anatomy surrounding
    isolated down / isolated up / coordinated down / coordinated up.

15. **WS16 — POTENTIAL→REALIZATION REVISIT** (19). Using sequence order,
    partial-order graph, failure mirrors, perturbation amplitude. Verdict
    CANDIDATE_CONVERSION_PRIMITIVE / LOCAL_CONVERSION_PATH / NO_SINGLE_PATH /
    NULL.

16. **WS17 — NODES / NULLS / FIELD MAP / VERDICTS** (20, 21, 22, summary,
    decision).
