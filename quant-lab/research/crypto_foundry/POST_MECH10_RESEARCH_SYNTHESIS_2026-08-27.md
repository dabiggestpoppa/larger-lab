## 1. Current phase transition in the research program

The program is moving away from asking only **what a state is** and toward asking:

- what local rules govern each patch,
- how those patches transition,
- how long they persist,
- how they respond to perturbation,
- how local responses propagate or fail to propagate,
- and how local behavior sits inside broader global constraints.

The working architecture remains:

**GLOBAL CONSTRAINT FIELD → LOCAL STATE → STATE AGE / SURVIVAL QUALITY → LOCAL ROUTE GATES → PERTURBATION RESPONSE → HEALTH STATE → DELIVERY CLOCKS → EXIT / REENTRY / PROPAGATION**

Direction should remain a **second-order consequence** of constraint resolution, not the primary object being directly optimized.

The guiding question is therefore not:

> Will price go up or down?

but:

> What state is the field in, which transitions remain available, how long can the current state survive, what perturbations matter locally, and what resolution branches remain open?

Directional expression can emerge later from this structure.

## 2. State age — current interpretation

State age is increasingly important, but **age itself should not yet be treated as the primitive**.

The more fundamental object appears to be:

**SURVIVAL-CONDITIONED STATE QUALITY**

MECH-10 supports the interpretation:

- strong HH episodes tend to be born stronger,
- weak HH episodes die young,
- surviving HH therefore becomes a selected higher-quality subset,
- separate within-episode maturation remains underpowered.

Potential future tests if needed:

- hazard conditioned on matched birth quality,
- matched-entry survival curves,
- renewal / semi-Markov treatment,
- conditional survival under comparable perturbations.

Do not keep trying to invent a hidden "maturation force" without stronger within-episode evidence.

## 3. Four-state breadth × dispersion system — deeper descriptive sensors

The 4-state machine remains a major structural object.

The current temporal interpretation is approximately:

- **HH**: active state that survives selectively and can develop strong delayed delivery,
- **HL**: participation without sufficient realization; decays with age,
- **LH**: dispersion/disorder with weaker participation that may slowly recruit,
- **LL**: compressed / inert state.

Future deepening may use additional **descriptive participation sensors**, not presumed drivers, such as where data permits:

- DEX volume,
- stablecoin activity,
- transaction activity,
- active-address proxies,
- perp participation,
- chain-local activity.

The correct question is not:

> Does DEX volume predict HH?

but:

> Does the same HH state contain meaningfully different participation anatomy depending on the kind of activity occurring inside it?

If a sensor adds no stable local information, merge or park it.

## 4. Temporal delivery should become a clock lattice

Do not compress timing into one lag.

The increasingly natural representation is:

**ENTRY CLOCK → FAILURE CLOCK → PERSISTENCE CLOCK → PROPAGATION CLOCK → EXIT CLOCK → REENTRY CLOCK**

Different states can have different hazard shapes.

Future work should continue tracking:

- state-conditioned arrival hazards,
- age-conditioned hazards,
- conditional-on-survival delivery,
- exit destination clocks,
- reentry clocks,
- local perturbation recovery latency.

The two-clock observation already survives in HH:

- failure/reentry reveals relatively fast,
- sustained propagation confirmation resolves more slowly.

This should remain central.

## 9. Health-state transitions — semi-Markov lens is likely superior to plain Markov

A simple Markov chain assumes next-state probability depends only on the present state.

The empirical field already shows **state age matters**, especially inside HH.

Therefore a **semi-Markov / duration-dependent transition framework** is likely a better mathematical lens because it allows:

**CURRENT STATE + DWELL TIME → TRANSITION HAZARD**

This fits the current state-age / hazard findings naturally.

Possible future use:

- health-state transition matrices,
- breadth×dispersion transition hazards,
- rehabilitation / decay paths,
- exit and reentry timing,
- duration-conditioned route probabilities.

Do not force a formal model until sample size and definitions support it.

## 11. Permission → realization — ask from a different angle

Do not repeatedly ask whether:

**breadth = permission** and **dispersion = realization**.

Instead ask:

> What changes in the field when participation is already high but realization has not yet occurred?

Then compare that field with the moment dispersion arrives.

This preserves falsifiability and avoids proving our own language.

Current directional evidence remains compatible with:

- breadth opening participation,
- dispersion marking differentiated realization,
- dispersion impulses mattering most in mature HH,
- breadth-only states exhausting if realization does not arrive.

Still descriptive / local until further validation.

## 12. Mathematical / scientific lenses worth preserving

### Immediate best fit

#### Semi-Markov / renewal processes
Useful because dwell time and state age materially affect transition hazards.

#### Competing-risk survival analysis
Useful for separate clocks such as:

- reentry,
- propagation,
- state exit,
- failure,
- rehabilitation.

#### Metastability / transfer-operator methods
Potentially useful because the empirical field increasingly resembles:

- inhabited regions,
- transient corridors,
- probability flow between states.

This could later use Perron–Frobenius / transfer-operator ideas without assuming deterministic dynamics.

#### Symbolic dynamics
Potentially strong lightweight lens for sequences such as:

`LL → HL → HH → HH → HL`

Could study:

- allowed / rare state words,
- recurrence,
- sequence entropy,
- local motifs,
- forbidden or unstable transitions.

This naturally matches:

**instance → sequence → pattern → formation → structure**.

### Useful but later / conceptual

#### Ecological / metapopulation state models
Potentially useful for degradation, dormancy, recovery, local extinction, reentry, and neighboring-patch effects.

#### Category theory / sheaf-style architecture
Potentially useful for describing:

- local objects,
- morphisms / transitions,
- composition of local rules,
- whether locally consistent structures glue into a coherent global field.

At present this should remain **architecture language**, not an empirical engine.

#### Topological data analysis
Potential future use for persistent regime geometry, but lower priority than the already-earned state / hazard tools.

#### Statistical mechanics / phase-transition language
Useful only cautiously. Strong-form bifurcation remains unearned.

### Current preferred mathematical stack

**SEMI-MARKOV + COMPETING RISKS + METASTABLE STATE-TRANSITION ANALYSIS**

This combination fits the evidence without forcing unnecessary complexity.
