Twitter Bookmarks Reader

Access and organize your Twitter/X bookmarks using OpenClaw's native browser automation. No API keys, no external services — just your already-logged-in Chrome browser.

Prerequisites

  • OpenClaw browser tool enabled and running (openclaw browser start)
  • Chrome browser with active Twitter/X login session
  • browser-automation skill (already installed — provides best practices)

Workflow

Step 1: Open Twitter Bookmarks

browser action="open" url="https://twitter.com/i/bookmarks" label="twitter-bm"

Wait 4-5 seconds for page load, then snapshot to verify login state.

Step 2: Verify Login

browser action="snapshot" targetId="twitter-bm" refs="aria"

If the page shows a login prompt, stop and tell the user to log into Twitter in Chrome first.

Step 3: Extract Bookmarks

Use browser action="act" with kind="evaluate" to extract bookmark data from the page:

// Extract all visible bookmark tweets
const tweets = document.querySelectorAll('[data-testid="tweet"]');
const results = [];
tweets.forEach(tweet => {
  const text = tweet.querySelector('[data-testid="tweetText"]')?.innerText || '';
  const user = tweet.querySelector('[data-testid="User-Name"]')?.innerText || '';
  const link = tweet.querySelector('a[href*="/status/"]')?.href || '';
  const time = tweet.querySelector('time')?.getAttribute('datetime') || '';
  if (text || link) {
    results.push({ text, user, link, time });
  }
});
return JSON.stringify(results);

Step 4: Scroll for More

Twitter bookmarks load infinitely. Scroll down to load more:

browser action="act" targetId="twitter-bm" request={"kind":"evaluate","fn":"() => window.scrollBy(0, 2000)"}

Wait 2-3 seconds, then extract again. Repeat until you have enough bookmarks or reach the desired date range.

Step 5: Organize and Save

Save extracted bookmarks to the workspace:

workspace/twitter-bookmarks/
├── index.md              # Master index
├── by-topic/
│   ├── ai.md
│   ├── trading.md
│   ├── tools.md
│   └── other.md
├── by-date/
│   └── 2026-05.md
└── links.md              # All extracted links by domain

"Pull my Twitter bookmarks"
"Get my saved tweets"

Filter by Topic

"Pull bookmarks about AI"
"/bookmarks --topic trading"

Summarize

"Summarize my twitter bookmarks"
"/bookmarks --summarize"

Extract Links

"Extract all links from my bookmarks"
"/bookmarks --links"

Error Handling

Error Solution
"Not logged in" User must log into twitter.com in Chrome first
"Page not loading" Wait longer, check internet connection
"Rate limited" Wait 60 seconds, retry
"Browser not running" Run openclaw browser start
Stale refs Re-snapshot the page before acting

Tips

  • Twitter bookmarks page requires JavaScript — browser automation is the only way without API
  • The profile="user" browser profile reuses your Chrome login — no separate auth needed
  • Scroll slowly to avoid rate limiting (2-3 seconds between scrolls)
  • Extract in batches of ~20 tweets at a time for best results
  • Save results after each batch to avoid losing data on errors
