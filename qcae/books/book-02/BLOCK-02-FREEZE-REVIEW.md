## Frozen Block 2 Invariants

1. Search capability semantics, not merely names.
2. Internal-first establishes the acquisition baseline.
3. Use multiple query families and implementation hypotheses.
4. Preserve query/source/revision provenance.
5. Curated inclusion is discovery evidence only.
6. GitHub stars and research citations are weak priors, not proof.
7. Package, repository, paper/specification, service, and internal implementation identities remain distinct.
8. Deduplicate repeated discovery without discarding discovery paths.
9. Deliberately preserve candidate-family diversity.
10. Escalate investigation cost progressively.
11. Rank next actions by expected information/capability value, not popularity.
12. Track saturation and terminate search rationally.
13. Label partial search as partial.
14. Preserve failed search and rejected paths as durable negative knowledge.
15. Discovery terminates in a candidate/escalation report, never an acquisition approval.
