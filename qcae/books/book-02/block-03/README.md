# Book II — Block 3: Repository Intelligence / DeepWiki Layer

**Status:** IN BUILD

## Objective

Turn a ranked candidate source into a source-grounded structural model answering: what is here, where is the relevant capability, what does it depend on, how did it evolve, and which discovery claims survive direct inspection?

DeepWiki is positioned as the natural comprehension half of discovery: GitHub and other sensors find candidate source; DeepWiki-style repository intelligence helps navigate and explain it. Explanation remains analysis. Source and reproducible evidence remain authoritative.
