# Book II — Block 2: Discovery Intelligence

**Status:** IN BUILD

## Objective

Define how QCAE converts capability contracts into high-recall, diversified, budget-aware discovery operations while preserving provenance and resisting popularity, vocabulary, ecosystem, and implementation-form bias.

## Chapters

- 2.1 Discovery Planner
- 2.2 GitHub Native Discovery
- 2.3 Curated Discovery Sensors
- 2.4 Ecosystem Discovery
- 2.5 Research Discovery
- 2.6 Internal Discovery
- 2.7 Discovery Ranking

## Required outputs

Block 2 must leave later agents with enough doctrine to implement:

- typed DiscoveryPlan objects;
- query-family generation;
- source adapters;
- internal-first search;
- candidate normalization and deduplication;
- discovery provenance;
- novelty/diversity control;
- budget allocation and stop rules;
- preliminary ranking for Block 3 repository intelligence.

Discovery does not prove capability. Its terminal product is a defensible candidate set plus evidence about why each candidate deserves or does not deserve deeper investigation.
