Define how a human operator or higher-level agent uses QCAE safely and consistently without needing to understand internal worker implementation details.

## Operating rule

The operator supplies intent, constraints, approvals, and business judgment. QCAE supplies evidence-backed intelligence. Neither prose confidence nor convenience substitutes for lifecycle state or authority.
