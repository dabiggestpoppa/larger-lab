## Build Doctrine

- build foundations before autonomy;
- schemas/domain before provider integrations;
- memory/evidence before long workflows;
- one real vertical slice before broad source coverage;
- security/sandbox before executing unknown code;
- generic proving before quant proving;
- standalone release before OCE wiring;
- chapter/subsystem commits before phase freezes;
- no phase advances while blocking exit criteria remain red.

The roadmap is authoritative for build order unless an explicit amendment is committed with downstream impact analysis.
