# Book VI — Block 17 Freeze Review

**Result:** READY TO FREEZE

## Frozen Operating Laws

1. Operators describe capability needs; QCAE normalizes implementation assumptions into contracts.
2. Repository-specific investigations do not bypass contract/evidence discipline.
3. Comparisons use shared contracts, hard gates, and common tests where feasible.
4. Reimplementation begins from specification/capability semantics and receives the same proving burden as adopted code.
5. Capability Receipts are the canonical human-readable decision artifact.
6. Integration approval is narrower than proving success and must state scope/action.
7. Research/paper-trading approval never implies live-capital authority.
8. Monitoring detects change but does not auto-upgrade protected integrations.
9. Upstream breakage uses known-good state, differential revalidation, rollback, and re-proof.
10. Security events trigger containment, blast-radius analysis, credential revocation, and governed restoration.
11. Retirement is graph-aware, authority-aware, and memory-preserving.
12. Urgency changes priority, never constitutional evidence/authority standards.
