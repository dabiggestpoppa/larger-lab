# Book V — Block 12: Agent Architecture

**Status:** IN BUILD

## Objective

Define the executable agent organism: one orchestrator, specialized workers, typed worker contracts, context isolation, deterministic handoffs, failure recovery, budgets, and human escalation.

## Chapters

- 12.1 Orchestrator
- 12.2 Specialized Workers
- 12.3 Worker Contracts

- 12.5 Handoffs

- 12.7 Budgeting
- 12.8 Human Escalation

## Block rule

No worker owns the entire truth. Workers produce typed evidence and recommendations. The orchestrator coordinates lifecycle progression but does not bypass evidence gates or authority boundaries.
