## Cross-Block Coherence

PASS — integration creates evidence/ownership objects Block 9 can receipt.

PASS — receipts expose exact invalidation dependencies Block 10 can watch.

PASS — continuous intelligence feeds changed evidence back into memory rather than mutating accepted capability silently.

PASS — internal capability census consumes the same receipt/evidence ontology used for external acquisition.

PASS — reverse acquisition reuses Books II/III instead of inventing a lower standard for replacement proposals.

PASS — negative knowledge prevents repeated failed acquisition and refactor loops.

PASS — standalone operation and future OCE authority remain compatible.

## Book IV Frozen Laws

1. Acquisition optimizes net capability gain, not repository adoption.
2. Quant Lab owns its capability interfaces.
3. Every integration is reversible by design proportional to risk.
4. Vendor/fork/dependency/reimplementation forms carry explicit ownership semantics.
5. Capability Receipts are the canonical bounded statement of trusted capability state.
6. Evidence is append-oriented, lineage-aware, and separable from interpretation.
7. Positive and negative knowledge are equally durable.
8. Every belief has scope and freshness.
9. Memory retrieval precedes redundant discovery/proving.
10. Changes trigger impact analysis, not automatic upgrades.
11. Differential revalidation is preferred when impact can be bounded; otherwise full proof returns.
12. Capability burden/value can drift without source change.
13. Ecosystem refresh compares challengers against the incumbent including switching cost.
14. Internal capability is continuously discoverable in the same atom ontology.
15. Internal duplication/consolidation is determined semantically.
16. Existing code receives neither automatic preference nor automatic rejection.
17. External replacements still obey the full acquisition/proving constitution.
18. CEREBUS semantics remain protected through internal consolidation.
19. Autonomous engineering intelligence may investigate and propose but not self-authorize mutation.
20. OCE later replaces authority transport/governance implementation without rewriting QCAE evidence semantics.

## Book V Entry Contract

Book V must turn Books I–IV into an executable multi-agent/runtime architecture while preserving:

```text
capability-first decomposition
evidence/claim separation
trust/authority separation
sandbox boundaries
receipt/memory semantics
bounded autonomy
standalone-now / OCE-later compatibility
```

**Decision: BOOK IV FROZEN v0.1.**
