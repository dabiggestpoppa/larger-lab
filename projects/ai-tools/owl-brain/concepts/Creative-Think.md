# Creative Think

> LATTICE framework for abstract reasoning. Activated when problems resist linear decomposition.

## When to Activate
- Abstract, philosophical, or multi-layered requests
- Problem space is undefined or shifting
- Linear decomposition fails
- Cross-domain synthesis required

## LATTICE Framework
1. **Layer** — Identify surface, structure, principle, meta layers
2. **Analogy** — Find analogous system in different domain
3. **Tension** — Name the core paradox/opposing forces
4. **Transform** — Invert, scale, remove/add constraints
5. **Integrate** — Synthesize into coherent model
6. **Challenge** — Stress-test the synthesis
7. **Express** — Deliver insight directly
