## 10 Caption Templates

### Template 1: The Curated Showcase
**Use for:** AI Art Showcase vertical, carousel posts
```
🔥 The AI art community cooked HARD this week

Here are {X} pieces that broke my brain:

→ {Teaser about #1}
→ {Teaser about #2}  
→ {Teaser about #3}

Which one hit different? Drop a number 👇

{CTA}
```
**Platform notes:**
- TikTok: Shorten to 2-3 lines max, put key text on-screen
- IG: Full version with line breaks between each point
- X: Thread format — main post = hook, replies = each image with commentary

### Template 2: The Prompt Drop
**Use for:** Prompt Breakdowns vertical
```
This prompt generates INSANE results every time 🤯

"{ACTUAL PROMPT HERE}"

3 things that make it work:
1. {Element 1}
2. {Element 2}  
3. {Element 3}

Save this for later 🔖
Try it and tag me — I wanna see your results
```
**Platform notes:**
- TikTok: Show prompt on-screen as text overlay, voiceover reading it
- IG: Put prompt in carousel slide 2, breakdown in caption
- X: Main post = prompt + best result, thread = breakdown

### Template 3: The Comparison
**Use for:** Model Reviews, Before/After verticals
```
I tested {MODEL A} vs {MODEL B} on the same prompt

The results? Not even close.

Swipe to see →

Which one wins? 1 or 2? Tell me below 👇
```
**Platform notes:**
- TikTok: Split-screen video format, text overlay with "1 or 2?"
- IG: Carousel with side-by-side slides
- X: Post both images in one tweet, poll if possible

### Template 4: The Trend Ride
**Use for:** Trending Reactions vertical
```
Everyone's talking about {TRENDING TOPIC}

{Result description}

What should I generate next?
```
**Platform notes:**
- TikTok: Use trending sound, fast cuts, on-screen text with trend name
- IG: Reel format with trending audio
- X: Single image + caption referencing trend

**Use for:** Before/After, educational content

```
Follow for more breakdowns like this 🔬
```

**Platform notes:**
- TikTok: Timelapse video format, text overlays for each step
- IG: Carousel with step-by-step slides
- X: Thread format, one step per reply

### Template 6: The Hot Take
**Use for:** Model Reviews, opinion content

- Always make the question genuinely related to content

## Platform-Specific Formatting Rules

### TikTok
- **Caption length:** Max 100-150 characters (short, punchy)
- **Emojis:** Use 2-3 max, strategically placed
- **Line breaks:** Single line, no paragraphs
- **Style:** Casual, direct, urgency-driven
- **Example:**
```
This AI prompt goes way too hard 🔥
Save it before it's gone 🔖
#aiart #fyp #stablediffusion
```

### Instagram
- **Caption length:** Up to 1,500 characters (longer, storytelling)
- **Emojis:** Use liberally as bullet points and visual breaks
- **Line breaks:** Essential — use between every 1-2 sentences
- **Style:** Aspirational, educational, community-focused
- **First line:** Must be the hook (visible before "more")
- **Example:**
```
🔥 The AI art community cooked HARD this week

Here are 5 pieces that broke my brain:

→ A cyberpunk city that looks more real than photos
→ A fantasy portrait with details that shouldn't be possible
→ An abstract piece that makes you feel things
→ A landscape that belongs in a museum
→ A character design that puts Hollywood to shame

Which one hit different? Drop a number 👇

.
.
.
#aiart #aiartcommunity #digitalart #midjourney #aiartist
```

### X (Twitter)
- **Caption length:** 280 chars per tweet (use threads for longer)
- **Emojis:** 1-2 max, don't overdo it
- **Line breaks:** Use for thread readability
- **Style:** Sharp, opinionated, punchy
- **Thread format:** Hook tweet → content tweets → CTA tweet
- **Example (Thread):**
```
Tweet 1: I tested 10 AI art models on the same prompt. Here's the ranking nobody asked for but everyone needs 🧵👇

Tweet 2: 10th place: [Model X] — [brief roast]
Tweet 3: 7th place: [Model Y] — [brief take]
...
Tweet 8: 1st place: [Model Z] — [why it won]

Tweet 9: What surprised you most? And what model did I miss?

Tweet 10: If this helped, RT the first tweet 🔄
```
