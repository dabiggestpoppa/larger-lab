## Recycling Rules

1. **Wait minimum 2 weeks** before recycling any content
2. **Change the hook/caption** — never repost identical content
3. **Cross-pollinate:** TikTok hits → Instagram carousels, X threads → TikTok scripts
4. **Update formatting** for current trends (new sounds, new editing styles)
5. **Track recycled content** separately to avoid over-posting the same source material
6. **Burn threshold:** If a piece gets <50% of average engagement on recycle, retire it permanently
