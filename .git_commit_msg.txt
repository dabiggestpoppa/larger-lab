TB-LIVE-EXEC-SEAL-03B: prove currency-neutral lot translation and restart-safe basket execution

Fixed the material defect in compute_currency_exposure() that used rounded_lots as a proxy for currency exposure and overwrote its configured max_residual_pct threshold.

Key fixes:
1. FIXED THRESHOLD VARIABLE BUG: Separated configured_max_residual_pct (gate threshold) from actual_max_residual_pct (measured value). Never overwrite the configured gate threshold.
2. REMOVED LOTS-AS-EXPOSURE PROXY: For each leg, derived real base/quote units from broker contract size: base_units = rounded_lots * contract_size, quote_units = base_units * executable_price. Then assigned signed currency exposures per leg (LONG GBPAUD: +base GBP, -quote AUD, etc.).
3. NORMALIZED EXPOSURES INTO ONE ACCOUNT CURRENCY: Converted GBP/AUD/NZD exposures to USD using live conversion rates (GBPUSD.PRO, AUDUSD.PRO, NZDUSD.PRO ticks) for both base and quote exposures.
4. DEFINED THE ACTUAL NEUTRALITY METRIC: max_currency_residual_pct = max(|GBP_usd|, |AUD_usd|, |NZD_usd|) / gross_basket_notional_usd * 100. Also reported L1_residual_pct and individual components.
5. PRESERVED THE CANONICAL MODEL WEIGHTS: Pipeline remains model_weight → weight_share → target USD notional → raw lots → rounded broker lots → actual base/quote notionals → actual currency exposures → residual hedge error. Did NOT modify canonical weights to make live execution look better.
6. MINIMUM-LOT DISTORTION TEST: Determined the minimum basket_notional_usd that allows all three legs to express canonical ratios within configured hedge-error tolerance. Search across realistic demo notionals ($500, $1,000, $2,500, $5,000, $10,000, $25,000, $50,000).
7. POLICY #7: If requested lot < volume_min and clamping to minimum creates hedge distortion above tolerance, REJECT BASKET with reason MIN_LOT_HEDGE_DISTORTION (do NOT auto-clamp and call it valid).
8. DEFINED INITIAL FORWARD-TEST CAPITAL SCALE: Selected the smallest demo basket notional that expresses canonical model weights sufficiently well, keeps residual exposure within threshold, and meets all broker volume constraints. Recorded as demo_basket_notional_usd (execution scalar only).
9. GATE K — REAL NEUTRALITY: Explicitly implemented the previously missing gate: actual residual currency exposure <= configured threshold. Tested across historical canonical weight examples, low ATR cases, high ATR cases, extreme weight imbalance cases, minimum-lot boundary, volume-step rounding boundary.
10. RE-RAN LOT TRANSLATION TESTS ACROSS REALISTIC WEIGHTS: Used canonical trade records from the 405-trade backtest. Sampled minimum, median, maximum weight configurations, 25th/75th percentile configurations, and preferably all 405 historical basket weight vectors. Reported median hedge error, 95th percentile hedge error, max hedge error, failure rate, minimum viable basket capital.
11. GATE F — EXECUTION RESTART: Made restart recovery an executable simulator test (not merely documentation). Scenario A: 3-leg basket OPEN → serialize execution state → simulate process death → instantiate new executor → broker still has 3 positions → reconcile → recover basket → assert no new orders sent.
