SECTION 1: CASCADE ACTIVATION LOGIC DEFINED
CASCADE ACTIVATION DEFINITION
■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■
1. Initial P90 (Bias Setter):
    First P90 candle in 2-11 AM EST window
    Establishes direction of constraint resolution [3] for session
    Standard Constraint Boundary [8]: 80% of P90 body
2. Cascade P90 (Momentum Confirmation):
    Subsequent P90 candle in SAME direction of constraint resolution [3]
    Must occur within 120 min of Initial P90
    New Constraint Boundary [8]: 168% of THIS P90 body (wider — allows normal partial rebalancing [6])
    Target: Same as Initial (-50% Asian Range constraint deficit resolution)
3. Maximum Cascades:
    Max 3 cascade activations per session
    Edge degrades after 3rd cascade

SECTION 9: COMPLETE CASCADE ACTIVATION PROTOCOL



CASCADE ACTIVATION WORKFLOW
■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■
STEP 1: Initial P90 Activation (2-11 AM EST)
  → Wait for P90 candle close >= threshold
  → Activate 40% size | Boundary: 80% of P90 body
  → Set direction of constraint resolution [3]: LONG or SHORT
  → Start 120-min resolution timer
STEP 2: 45-Min Add Check (+45 min from Signal 1)
  → Check if resolution output extended +8 pips
  → If YES: Activate 30% size | Boundary: Breakeven (Signal 1 output)
  → If NO: Skip, wait for cascade signal
STEP 3: Cascade P90 Check (30-90 min from Signal 1)
  → Watch for new P90 candle in SAME direction of constraint resolution
  → If SAME: Activate 20% size | Boundary: 168% of THIS P90 body (Stall Zone [10])
  → If OPPOSITE: IGNORE (opposite direction = noise, not reversal)
STEP 4: Cascade 2 P90 Check (60-90 min from Signal 1)
  → If SAME direction: Activate 10% size | Boundary: 168% of THIS P90 body
  → STOP here (max 3 cascades — resolution momentum exhausts at 4th+)
STEP 5: Exit Management
  → TP1 (-25%): Close 50% of total, move boundary to Breakeven
  → TP2 (-50%): Close remaining
  → Hard Exit (12 PM EST): Close ALL (constraint resolution window ends)
  → Kill Switch (132% State [10]): Close ALL immediately
