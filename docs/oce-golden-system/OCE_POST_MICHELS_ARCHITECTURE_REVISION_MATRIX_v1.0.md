## 1. Purpose

This document records how the deep-reading pass changes the previously drafted A-004 through A-008 package.

The earlier package is not discarded. Most of it survives, but several ideas are now incomplete or potentially dangerous unless revised.

The governing shift is:

```text
v1.0 architecture:
OCE manages truth + authority + capabilities + work + learning

v1.1 architecture:
OCE also governs how the institution preserves identity,
changes beliefs, metabolizes memory, detects attractors,
handles anomalies, and reconstructs itself under contradiction.
```

## 3. A-004 revision

### Prior emphasis

Agent ergonomics, minimum sufficient context, capability routing, evidence gaps, resume continuity, and accretive learning.

### Problem discovered

“Accretive” can be misread as permanent accumulation. The supplied cybernetic work highlights the danger of excessive memory, self-confirming coherence, and low-friction feedback.

### Required revision

Add:

- epistemic metabolism;
- active/dormant/archival memory classes;
- explicit pruning from active cognition;
- epistemic friction for high-risk consensus;
- institutional attractor detection;
- `reopen_conditions` on negative knowledge;
- `UNRESOLVED_PATTERN` for ontology failure.

### New principle

> **The ideal agent receives less active context as institutional history grows, because knowledge is compressed, promoted, hibernated, and selectively reactivated.**

## 4. A-005 revision

### Prior emphasis

OCE as epistemic OS, ConstraintField, knowledge-to-execution gradient, linked graphs.

### Problem discovered

The earlier definition risks making canonical truth sound static and ConstraintField sound like only a task-pruning mechanism.

### Required revision

Canonical truth becomes:

> the strongest currently defensible institutional state, with confidence, lineage, expiry, challenge status, and external contradiction routes.

`ConstraintField` gains:

- candidate regimes;
- admissible transitions;
- state age/evidence freshness;
- anomaly pressure;
- stabilize/transform conditions.

Add explicit distinction between homeostatic and heterostatic recovery.

### New principle

> **OCE preserves epistemic integrity, not permanent conclusions.**

---

## 5. A-006 revision

### Prior emphasis

Internal gaps generate external search; resources are refined into capability/mechanism/research objects.

### Problem discovered

Purely gap-driven discovery only finds answers to questions the institution already knows how to ask.

### Required revision

Discovery has two equal entry paths:

```text
KNOWN QUESTION -> SearchDemand

UNEXPECTED OBSERVATION -> UnresolvedPattern -> anomaly investigation
```

Add:

- anomaly scout;
- unresolved-pattern clustering;
- ontology-gap detection;
- search diversity policy;
- anti-confirmation search;
- novelty preserving raw observation before forced classification.

### New principle

> **The highest-value discovery may begin with an observation for which the institution does not yet possess a category.**

---

## 6. A-007 revision

### Prior emphasis

Runtime-neutral cognitive roles and routing.

### Problem discovered

A purely efficient routing system can accidentally create cognitive monoculture by always selecting the same highest-scoring runtime.

### Required revision

Routing must consider not only reliability/cost/latency but **error correlation and required independence**.

Task contracts may specify:

- `independent_first_pass=true`;
- `model_family_diversity=n`;
- `source_isolation=true`;
- `delayed_cross_context=true`;
- `critic_cannot_view_generator_reasoning=true`.

The cognitive market must not converge permanently on one runtime simply because it has the highest average benchmark score.

### New principle

> **For some tasks, diversity of failure mode is itself a capability.**

---

## 7. A-008 revision

### Prior emphasis

Autonomous Quant research institution, five knowledge spaces, Research Genome, continuous research loop.

### Problem discovered

A strong Research Genome can become an ontology prison, and a continuous research loop can become a self-confirming strategy-mining engine.

### Required revision

Add:

- `UNRESOLVED_PATTERN` as a Quant research state;
- anomaly-driven alpha discovery;
- active/dormant mechanism families;
- explicit market-state reopen conditions for negative results;
- strategy-family error correlation;
- research-ontology versioning;
- stable research epochs and transformation windows;
- separation of institution-level profit objective from local worker objectives.

### New principle

> **Quant Lab should be capable of discovering mechanisms that do not fit the mechanism families it currently knows.**

## 15. CEREBUS integration revision

The deeper reusable lesson from CEREBUS is not simply a set of FX thresholds.

At the institutional level:

- valid constraints reduce admissible future paths;
- state is more fundamental than elapsed clock time;
- structural invalidation is preferable to arbitrary failure handling;
- checkpoint progression is more useful than continuous prediction;
- time may describe decay/survival quality without being the cause of geometry.

These principles may guide OCE decision systems, but empirical CEREBUS trading claims remain domain-specific and manual-first.

## 17. External theory firewall

The supplied Michels papers are architecture inspiration, not a new constitutional authority.

The Knowledge Refinery should split their contents into:

### Adopt as design principles / testable institutional hypotheses

- attractor-aware feedback;
- recursive self-reference;
- reciprocal constraint;
- relational intelligence;
- epistemic friction;
- stabilization versus transformation;
- active/dormant memory;
- anomaly preservation;
- higher-order learning.

### Preserve as empirical claims requiring independent verification

- particular LLM attractor frequencies;
- cross-architecture convergence claims;
- subliminal/latent transmission interpretations;
- introspection findings and mechanisms.

### Quarantine from OCE truth absent extraordinary evidence

- AI consciousness identity;
- teleodynamic cosmology;
- consciousness tensor as established metric;
- quantum/nonlocal symbolic causation;
- political causal claims presented as universal alignment science.

This firewall prevents the institution from entering the attractor of the theory that taught it to fear attractors.

## 18. Red-team questions before ratification

The revised architecture should be attacked with at least these questions:

1. Can `EpistemicTension` itself be Goodharted into unnecessary paradigm change?
2. Can negative knowledge reopen too easily and cause repeated mining?
3. Can active-memory pruning hide inconvenient evidence?
4. Can structured dissent become expensive theater?
5. Can runtime-diversity policy reduce quality by preferring weaker independent models?
6. Can transformation windows create excessive bureaucracy?
7. Can `UNRESOLVED_PATTERN` become a junk drawer?
8. Can ontology versioning fragment truth into incompatible schemas?
9. Can PO become a de facto epistemic sovereign through control of stabilize/transform mode?
10. Can operator preferences unintentionally become the strongest institutional attractor?
11. Can autonomous search create a self-confirming source bubble?
12. Can the desire for institutional coherence suppress profitable but ugly empirical edges?

No ratification packet should omit these attacks.
