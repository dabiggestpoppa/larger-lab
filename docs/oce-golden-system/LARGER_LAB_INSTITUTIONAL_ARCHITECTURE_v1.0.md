## 0. North Star

Larger Lab is not a trading application, agent framework, model host, backtester, data warehouse, or collection of useful tools. It is a durable institutional substrate for creating, operating, validating, replacing, and compounding specialized intelligent systems.

OCE is not the product. OCE is the epistemic and constitutional operating system inside Larger Lab. It governs what is known, why it is believed, who may act, which evidence is sufficient, what remains unresolved, how state survives interruption, and how capability changes become trustworthy.

The target is not a good machine that produces good outputs. The target is a factory capable of repeatedly producing, evaluating, repairing, replacing, and improving great machines without surrendering the foundation to any one runtime, model, framework, strategy family, data provider, or external project.

The permanent competitive objective is therefore:

> **Absorb better technology faster than competing systems can reorganize around it, while preserving truth, authority, evidence, reproducibility, and accumulated scientific knowledge.**

## 1. Institutional invariants

### 1.1 Replaceable cognition

No model, agent runtime, framework, or vendor is part of the permanent identity of Larger Lab.

Hermes, OpenClaw, Pi, hosted LLMs, local models, future reasoning architectures, and later replacements are implementations of runtime-neutral roles and capability contracts.

A runtime may disappear without destroying:

- canonical state;
- evidence lineage;
- authority;
- project state;
- research history;
- capability definitions;
- negative knowledge;
- strategy lineage;
- experiment history;
- operator decisions;
- restart continuity.

The institution owns the knowledge. The runtime temporarily reasons over it.

### 1.2 Progressive executability of knowledge

Institutional learning must move toward lower future reasoning cost and stronger machine enforcement.

Preferred promotion gradient:

```text
RAW SOURCE
  -> CLAIM
  -> OBSERVATION
  -> NORMALIZED FACT / HYPOTHESIS
  -> MECHANISM CANDIDATE
  -> VALIDATED RELATIONSHIP
  -> PRACTICE
  -> PROCEDURE
  -> TEST
  -> POLICY / TEMPLATE
  -> CAPABILITY
  -> GOVERNED AUTONOMOUS BEHAVIOR
```

The institution becomes smarter primarily by crystallizing validated reasoning into reusable structure, not by accumulating unbounded prose memory.

### 1.3 Endogenous search

External discovery is driven by unresolved internal state, not only by generic feeds or schedules.

Search demand may originate from:

- capability gaps;
- evidence gaps;
- sensor gaps;
- data-quality limits;
- unresolved contradictions;
- repeated worker friction;
- scientific uncertainty;
- portfolio weakness;
- execution bottlenecks;
- model drift;
- cost or capacity constraints;
- repeated failed experiments;
- new market structures or provider changes.

The institution must learn not only from answers, but from which questions proved valuable.

### 1.4 Observation before prediction

Across engineering and markets, claims about future behavior never outrank observable present state and verified mechanism evidence.

The shared doctrine is:

- state before action;
- constraints before direction;
- potential is not realization;
- local and global conditions may differ;
- time may alter survival or transition probability without creating underlying geometry;
- failure is information;
- null results are valid answers;
- named models are not imposed without incremental evidence;
- research stops when available observation cannot resolve the remaining question.

### 1.5 External intelligence is candidate material

Imported code, papers, strategies, model claims, social observations, datasets, APIs, and external systems never become canonical truth merely because they are popular, polished, profitable-looking, or agent-recommended.

Every external object enters with provenance, rights, version, scope, confidence, and an explicit evidence status.

## 2. The institutional tower

Larger Lab is organized as a tower of linked abstractions. Each higher layer consumes stable projections from the layer below instead of loading the entire institution into agent context.

```text
L0  CONSTITUTIONAL LAW
    authority, invariants, prohibitions, change rules

L1  WORLD TRUTH
    canonical state, source provenance, evidence, contradictions

L2  CAPABILITY FIELD
    what can be done, by whom, at what cost/risk/evidence quality

L3  WORK FIELD
    goals, plans, dependencies, tasks, grants, checkpoints, recovery

L4  DOMAIN STATE
    quant, crypto, applications, infrastructure, future domains

L5  SCIENTIFIC EVIDENCE
    experiments, mechanisms, nulls, robustness, causal limits

L6  PRACTICE / NEGATIVE KNOWLEDGE
    promoted methods, anti-patterns, failure surfaces, reusable lessons

L7  OPERATOR DECISION SURFACE
    minimum sufficient projection for high-value human judgment
```

The agent context is a projection of this tower, never a substitute for it.

## 3. Core institutional graphs

The long-run system is better modeled as interlocking graphs than as isolated databases.

### 3.1 Evidence Graph

Links claims to sources, observations, experiments, contradictions, reviewers, confidence, expiry, and downstream dependents.

Primary question:

> Why should the institution believe this?

### 3.2 Capability Graph

Links capabilities to implementations, inputs, outputs, prerequisites, authority, risk, cost, latency, evidence quality, known failures, substitutes, and consumers.

Primary question:

> What is the cheapest admissible path capable of producing evidence strong enough for the current objective?

### 3.3 Work Graph

Links objectives, plans, dependencies, tasks, workers, expected artifacts, evidence gaps, stop conditions, checkpoints, and cleanup obligations.

Primary question:

> What remains to resolve the objective, and what may safely happen next?

### 3.4 Source Graph

Links external and internal resources to versions, authors, licenses/rights, claims, extracted mechanisms, strategy atoms, capability atoms, datasets, and related prior research.

Primary question:

> What does this resource actually add that the institution does not already possess?

### 3.5 Research Genome

Represents reusable research atoms independently from whole strategy files.

Candidate atoms include:

- observation;
- mechanism;
- state filter;
- entry;
- exit;
- invalidation;
- risk;
- sizing;
- execution;
- portfolio interaction;
- validation method.

A failed whole strategy may still contain useful atoms. A winning strategy may contain fragile or redundant atoms. Promotion occurs at the smallest defensible abstraction.

### 3.6 Negative Knowledge Graph

Stores falsified, demoted, blocked, context-limited, unsafe, duplicated, non-reproducible, or data-insufficient paths with scope and evidence.

Primary question:

> What should we avoid repeating unless a materially new mechanism, state, sensor, dataset, or assumption changes the problem?

## 4. ConstraintField — universal decision primitive

A `ConstraintField` is a machine-readable projection of the active admissible state space for an objective.

It does not predict one answer. It narrows the set of lawful and evidentially meaningful next actions.

A field may include:

- objective and completion condition;
- known state;
- unknown state;
- active authority;
- required evidence;
- prohibited actions;
- dependencies;
- available capabilities;
- budgets;
- risk limits;
- known negative knowledge;
- rollback or reversibility;
- competing alternatives;
- unresolved contradictions;
- expiry and restart information.

The CEREBUS-compatible institutional principle is:

> **As valid constraints accumulate, the admissible action space should shrink. Agent quality is partly measured by how efficiently it resolves that constrained field rather than expanding possibility unnecessarily.**

The Quant and Crypto domains may define specialized ConstraintField projections while preserving the same institutional contract.

## 5. Cognitive roles

### 5.1 Operator

Final authority, architectural sovereign, capital authority, and ultimate reviewer of high-consequence ambiguity.

The system should progressively reduce routine operator burden without obscuring important uncertainty or irreversible decisions.

### 5.2 Hermes — Companion role

Hermes is the preferred human-continuity companion: conversation, personal continuity, reminders, lightweight work, summaries, and bounded referral.

Hermes is not canonical operational truth and does not become Quant Lab executive authority.

### 5.3 PO — Executive cognition

PO is the chief institutional operator. It interprets goals, allocates work, resolves ConstraintFields, chooses capability paths, controls research priorities, synthesizes evidence, and escalates high-value operator decisions.

PO does not personally need to execute every task.

### 5.4 Worker Fabric

OpenClaw, Pi, future coding agents, browser workers, research runtimes, local models, cloud workers, and deterministic executors are implementations within a runtime-neutral Worker Fabric.

OpenClaw is currently best treated as a broad autonomous worker/orchestration runtime candidate. Pi is currently a strong narrow engineering-worker candidate. Neither owns institutional authority.

### 5.5 Science Fabric

QCAE and future research agents operate as bounded scientific reasoners over domain observations, Research Genome, experiments, nulls, negative knowledge, and deterministic validation kernels.

Science agents may generate hypotheses and synthesize evidence. They do not certify their own claims or bypass sealed validation.

## 6. Runtime neutrality and cognitive routing

Every cognitive runtime shall be certified against role contracts rather than permanently named in architecture.

A future `AdaptiveReasoner` / `WorkerRuntime` contract should expose at minimum:

- supported modalities and tools;
- context limits;
- task classes;
- deterministic interfaces;
- reliability history;
- sandbox compatibility;
- latency;
- cost;
- privacy boundary;
- evidence behavior;
- interruption/restart behavior;
- capability ceiling.

Long-run routing may function like a governed cognitive market.

Tasks publish requirements; runtimes advertise verified capabilities. OCE selects the cheapest admissible route that satisfies evidence, authority, risk, and latency requirements.

Intelligence is assumed to become abundant. The architecture therefore treats high-quality evidence, unique data, validated capabilities, clean ontology, historical experiments, trust, and good questions as more durable scarce resources than model tokens.

## 7. Dual institutional flywheel

### 7.1 Outward cognition loop

```text
INTERNAL UNCERTAINTY
  -> QUESTION / SEARCH DEMAND
  -> DISCOVERY
  -> RESOURCE CANDIDATES
  -> INGESTION
  -> NOVELTY / RELEVANCE
  -> EXPERIMENT / SANDBOX
  -> KNOWLEDGE
```

### 7.2 Inward evolution loop

```text
KNOWLEDGE
  -> BETTER CAPABILITIES
  -> BETTER PRACTICES
  -> BETTER AGENT ROUTING
  -> BETTER EXPERIMENTS
  -> BETTER WORLD MODEL
  -> BETTER QUESTIONS
  -> OUTWARD COGNITION
```

The institution is accretive only if both loops close.

Raw resources are ore. Agents should not repeatedly reread large raw corpora when a validated higher-level representation exists.

```text
PAPERS / REPOS / STRATEGIES / DATASETS / DOCS / INTERNAL BRANCHES
                         |
                         v
                  SOURCE NORMALIZATION
                         |
             +-----------+------------+
             |           |            |
             v           v            v
       CAPABILITY     MECHANISM     RESEARCH
          ATOMS         CARDS        GENOME
             |           |            |
             +-----------+------------+
                         |
                         v
                    EVIDENCE GRAPH
                         |
                 +-------+-------+
                 v               v
              POSITIVE        NEGATIVE
              KNOWLEDGE        KNOWLEDGE
                 +-------+-------+
                         v
                    AGENT COCKPIT
```

Progressive disclosure requires refined summaries by default and exact source expansion only when evidence needs it.

## 9. Autonomous discovery doctrine

Discovery is a governed institutional function, not a browsing hobby.

Scout classes may include:

- capability scout;
- GitHub/release scout;
- academic/paper scout;
- dataset/provider scout;
- market-structure scout;
- crypto-source scout;
- execution/microstructure scout;
- internal archaeology scout;
- dependency/security scout.

Every candidate receives a novelty disposition such as:

- already covered;
- stronger implementation of existing capability;
- partially owned capability;
- unverified candidate;
- new sensor/data surface;
- new mechanism/research hypothesis;
- new execution/infrastructure capability;
- reusable agent/coding capability;
- blocked by data/rights/cost;
- rejected/duplicate;
- high-value strategic candidate.

Search policy learns from promotions, failures, costs, unresolved evidence gaps, and later realized institutional value.

## 10. Quant institution architecture

Quant Lab is not primarily a backtesting product. It is a scientific institution spanning five knowledge spaces.

```text
OBSERVATION SPACE
    data / sensors / market states
          |
          v
MECHANISM SPACE
    structural hypotheses / causal limits
          |
          v
STRATEGY SPACE
    mechanism -> conditional action mappings
          |
          v
EXECUTION SPACE
    fills / cost / venue / latency / capacity
          |
          v
EVIDENCE SPACE
    falsification / robustness / OOS / lineage
```

No strategy is promoted merely because an agent generated it or because an imported project reports attractive performance.

External quant systems such as FMZ, QuantMind, research repositories, papers, and future projects are capability and hypothesis donors beneath the institutional agents. Useful components may be forked, adapted, reimplemented, wrapped, or isolated after technical and license review. They do not replace the canonical Quant Foundation.

### 10.1 Strategy / Research Genome

Large strategy corpora are decomposed into mechanism and implementation atoms so thousands of files can collapse into smaller families of genuinely distinct ideas.

This permits:

- deduplication;
- cross-market transfer studies;
- component-level success/failure learning;
- mechanism-family statistics;
- compatibility analysis;
- regime conditioning;
- evidence-aware strategy synthesis.

Agent-generated strategy design should prefer grounded recombination and novel mechanism inference over invention from generic model priors.

## 11. Crypto OS as specialized observatory

Crypto OS is a governed domain under Larger Lab/OCE, not an independent top-level authority.

Its long-run structure may include:

```text
SENSOR FABRIC
  -> MECHANICAL FIELD
  -> GLOBAL FIELD + LOWER FIELD
  -> ONCHAIN / CROSS-CHAIN FLOW
  -> CREDIT / YIELD
  -> CAPITAL FIELD
  -> PROTOCOL ECONOMICS / RWA
  -> MARKET HEALTH
  -> CAPITAL ROUTING
  -> RESEARCH / STRUCTURAL ALPHA
```

The current research doctrine — provider-native semantics, observation before derivation, null preservation, finite resolution, global/local separation, potential-versus-realization, and evidence-bounded promotion — is a model for the broader institution.

Crypto-derived primitives may later generalize into shared Quant capabilities only after their domain assumptions are made explicit.

## 12. Larger Lab mines itself

External discovery and internal archaeology use the same refinery.

Older branches, superseded engines, experiments, repair records, TB Forward research, MVE, CEREBUS reproductions, capital-routing work, abandoned systems, agent tooling, and prior infrastructure are candidate resources.

Internal age does not imply irrelevance; historical artifacts may contain reusable mechanisms, tests, engineering practices, execution logic, negative knowledge, or capability atoms.

No internal legacy claim bypasses current evidence standards.

## 13. Anti-obsolescence doctrine

The institution must remain valuable if:

- current LLM architectures become obsolete;
- model costs collapse;
- agent runtimes change completely;
- cloud providers disappear;
- a superior backtester is released;
- market data vendors change;
- execution APIs change;
- new asset classes emerge;
- future reasoning systems use different computational paradigms.

To achieve this, durable state resides in stable institutional contracts and graphs, while volatile technology lives behind adapters.

The architecture should prefer replacement boundaries over framework inheritance.

## 14. Operator end state

The desired operator experience evolves from manual scavenging and supervision toward high-value direction and review.

Target interaction classes include:

- What did the lab learn?
- Which uncertainties matter most?
- Which external discoveries materially improve us?
- Which capabilities are currently weak?
- Which three experiments have highest information value?
- What new uncorrelated opportunities deserve research?
- What changed in market state or strategy health?
- Why does the institution believe this claim?
- What should be stopped, demoted, or rebuilt?

The operator should not need to continually search social media, GitHub, papers, or releases for the institution to remain current.

## 16. Falsification tests for this architecture

This architecture is wrong if it causes any of the following:

1. A named agent runtime becomes irreplaceable institutional truth.
2. More accumulated knowledge requires proportionally more prompt context.
3. External discovery becomes generic feed ingestion without internal demand.
4. Imported strategy count is mistaken for research quality.
5. Agent memory substitutes for evidence or canonical state.
6. Research agents can certify their own profitable claims.
7. Crypto OS or Quant Lab bypasses OCE authority/evidence boundaries.
8. More agents increase authority ambiguity or duplicated state.
9. Old failures are repeatedly rediscovered because negative knowledge is not queryable.
10. A future technological paradigm shift requires rebuilding the institutional foundation.
