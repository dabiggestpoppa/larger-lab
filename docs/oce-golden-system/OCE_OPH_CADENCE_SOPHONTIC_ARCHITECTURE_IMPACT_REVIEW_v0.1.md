## 0. Decision

The synthesis does **not** justify rewriting the institutional architecture.

Most of its strongest conclusions already exist in OCE:

- A-004 places canonical state outside the model and requires cold reconstruction;
- A-005 defines OCE as the institutional truth, evidence, authority, state, and recovery layer;
- A-007 makes cognitive runtimes replaceable and non-authoritative;
- A-009 separates useful cybernetic architecture from unverified consciousness and physical claims;
- A-010 protects plural models, explicit unresolved states, frozen evaluation, and operator sovereignty;
- the survival plan already tests worker, runtime, provider, state, authority, evidence, and mission continuity;
- the stress suite already tests runtime replacement, correlated consensus, forced coherence, self-evaluation corruption, and authority expansion.

The review finds five narrow existing-architecture gaps and two genuinely new program additions.

### Narrow gaps

1. private imagination is not yet explicitly separated from witnessed evidence;
2. consensus is not yet explicitly limited to nominating a candidate public claim;
3. runtime replacement tests reconstructability but not a complete continuation-equivalence contract;
4. attractor language is quarantined, but causal intervention requirements should be sharper;
5. transformation admissibility does not yet explicitly require continuation impact and protected-observation preservation.

### New additions

1. **A-012 — Model-Sparse Institutional Intelligence**;
2. **MF-A002 — System-One and Cognitive Primitives**.

No blocking contradiction was found. The correct action is a narrow patchset plus the two additions, not a new OCE or a new cognitive-runtime dependency.

## 3. Contradiction analysis

### C-01 — OPH consensus language versus OCE evidence authority

**Apparent conflict:** OPH describes a public world emerging through observer overlap and disagreement repair. A literal import could make consensus truth-producing.

**Resolution:** OCE retains evidence authority.

```text
overlap / agreement
  -> candidate public claim
  -> provenance + independence + policy + verification
  -> canonical promotion or explicit obstruction
```

Consensus is coordination evidence. It is never sufficient truth authority.

**Result:** no contradiction after translation; explicit patch required in A-005.

### C-02 — Private cognitive state versus canonical institutional state

**Apparent conflict:** Cadence-style persistent state and imagination may be essential to cognition, while A-004/A-007 forbid model memory from becoming canonical.

**Resolution:** the states have different roles.

- private state may support prediction, simulation, planning, and local continuity;
- only a governed promotion event may create a canonical institutional record;
- generated counterfactuals retain `SIMULATED` or equivalent provenance;
- runtime loss may destroy private state without destroying institutional truth.

**Result:** compatible; explicit private-imagination firewall required.

### C-03 — Persistent identity versus replaceable runtimes

**Apparent conflict:** sophontic development implies continuing identity, while A-007 allows arbitrary runtime replacement.

**Resolution:** replacement is allowed only inside a declared role/capability envelope. Institutional continuity belongs to OCE; cognitive-organ continuation is a narrower, testable behavioral claim.

**Result:** A-007 needs a `CognitiveContinuationContract`; no model gains permanent identity authority.

### C-04 — Organic alignment versus hard authority

**Apparent conflict:** A-009 cultivates healthy attractors, which could be interpreted as allowing learned internal alignment to replace constitutional controls.

**Resolution:** A-009 already separates organic from constitutional alignment. The patch makes clear that attractor evidence never grants credentials, deployment, capital, policy, or self-ratification authority.

**Result:** no doctrinal contradiction; causal-proof language should be tightened.

### C-05 — Self-development versus frozen evaluation

**Apparent conflict:** sophontic self-revision requires changing how the system learns, while A-010 freezes the rule evaluating a current transformation.

**Resolution:** the current evaluation contract remains frozen. Proposed changes become a separately versioned future transformation candidate. Self-development is compatible with non-retroactive evaluation.

**Result:** compatible; continuation impact becomes an admissibility input.

### C-06 — Model sparsity versus capable general reasoning

**Apparent conflict:** “model-sparse” could be interpreted as banning general models even when they are the cheapest admissible route.

**Resolution:** model-sparse is a dependency and routing doctrine, not anti-model ideology. General reasoners remain eligible when narrower methods cannot close the evidence gap at the required risk and cost.

**Result:** new A-012 must preserve evidence-based routing rather than encode a rigid universal ladder.

### C-07 — Morphology as cognition versus implementation neutrality

**Apparent conflict:** if topology, memory placement, and ports affect cognition, then implementation may not be behaviorally neutral.

**Resolution:** runtime neutrality means constitutional and interface neutrality, not empirical equivalence. Morphology changes require re-evaluation when they can change protected behavior.

**Result:** add morphology to continuation and evaluation scope; do not freeze one topology.
