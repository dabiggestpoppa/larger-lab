# Tweet Templates

## Stat Bomb
```
[IMPOSSIBLE-SEEMING STAT]
[Context that makes it real]
[Optional: credibility marker]
```

## Thread Starter
```
[HOOK: Pattern interrupt or contrarian claim]
🧵 [What the thread proves, numbered]
```

## Provocation
```
[Common belief in trading]
[Why it's wrong — with data]
[Alternative truth]
```

## Proof Tweet
```
[Specific number] trades.
[Specific result].
[Timeframe/sample size].
[One-line implication]
```
