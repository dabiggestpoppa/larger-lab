# TikTok/Reels Script Template

## Structure (30-60 seconds)

### HOOK (0-2 sec)
- Pattern interrupt or impossible claim
- On-screen: [TEXT GRAB]
- Visual: [SHOT DESCRIPTION]

### SETUP (2-15 sec)
- Context for why this matters
- Build tension/curiosity

### PAYOFF (15-45 sec)
- The actual data/truth
- Walk through the proof
- Use specific numbers

### CTA (45-60 sec)
- "Follow for [specific value]"
- "Part [X] drops tomorrow"
- "Comment [word] for the full breakdown"

## Visual Style
- Clean text overlays
- Chart screenshots with annotations
- Split screen: "What they say" vs "What the data says"
- Green/red color coding for win/loss
