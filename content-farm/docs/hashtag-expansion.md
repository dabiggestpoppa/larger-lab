## 📊 Hashtag Strategy Overview

### Principles
- **Mix popularity tiers:** High-volume (reach) + Medium (competition) + Niche (targeting)
- **Platform-native behavior:** Instagram allows 30 but 8-15 is optimal; TikTok 3-5; X 1-3; Reddit 0 (use flairs); Pinterest 2-5 keyword hashtags
- **Rotate sets:** Never use identical sets on consecutive posts to avoid shadowban
- **Track performance:** Log engagement per hashtag set weekly

### Popularity Tier Key
- 🔴 High (1M+ posts) — broad reach, high competition
- 🟡 Medium (100K-1M) — balanced reach/competition
- 🟢 Niche (<100K) — targeted, high conversion, low competition

## 🔑 Key Insights

1. **Instagram:** Use 10-15 hashtags per post. Mix 3-4 high-volume with 6-8 medium and 3-4 niche. Rotate sets to avoid shadowban.
2. **TikTok:** Use 3-5 hashtags. Prioritize trending + niche. #fyp and #foryou are saturated — only use if space allows.
3. **X/Twitter:** Use 1-3 hashtags max. More than 3 reduces engagement. Prioritize conversation-starting tags.
4. **Reddit:** No hashtags — use flairs and keywords in titles. Title format matters more than tags.
5. **Pinterest:** Use keyword-rich descriptions (200+ chars) rather than hashtag-style tags. Board titles matter more.
6. **YouTube:** Tags matter less than titles/descriptions. Focus on long-tail keywords in descriptions.
