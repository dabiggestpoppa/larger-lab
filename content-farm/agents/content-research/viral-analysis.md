## Format 1: "Summer Glow Up" AI Transformation

### What It Is:
The dominant AI art format on TikTok right now. A raw/unstyled selfie or photo transforms into a cinematic, AI-enhanced "it girl/it boy" version, synced to a trending audio beat drop.

### Why It Works:
- **Extreme visual contrast** — Boring "before" vs stunning "after" creates dopamine hit
- **Identity fantasy** — Viewers imagine themselves as the "after" version
- **Seasonal relevance** — "Summer Glow Up 2026" is THE seasonal trend
- **Loopable** — End frame loops back to beginning for rewatch
- **Audio synergy** — Transformation synced to beat drop = satisfying

### Structure (8-12 seconds):
```
0-2s: Raw photo/selfie + text overlay ("Before my summer glow up")
2-3s: Beat drop + transition (liquid dissolve, flash, snap)
3-10s: AI-enhanced version (cinematic lighting, golden hour, editorial)
10-12s: Loop back to start or hold on "after"
```

### Trending Audios:
- "Be Her" by Ella Langley (envy/glow-up anthem)
- "Take Her Swimming" trend audio
- "Devil Wears Prada 2" boss energy edits

### How to Adapt for Our Verticals:
| Vertical | Adaptation |
|----------|-----------|
| **AI Art Showcase** | Show raw prompt → AI masterpiece transformation |
| **Before/After** | Classic selfie → AI portrait (direct application) |
| **Prompt Breakdown** | "Before: basic prompt" → "After: optimized prompt" side-by-side |
| **Model Reviews** | Same prompt in Model A (before) vs Model B (after) |
| **Trending Reactions** | React to trending content with AI transformation |

### Example Prompts:
- "Cinematic summer glow-up transformation sequence, radiant woman emerging from pool, golden hour light, hyper-realistic, fashion editorial, 9:16"
- "AI-enhanced portrait, professional headshot, studio lighting, shallow depth of field, photorealistic"

## Format 2: "AI Change Person" Face Swap

### What It Is:
Users transform into celebrities, anime characters, K-pop idols, or fantasy versions of themselves using AI face swap tools (KlingAI, CapCut templates, dedicated face swap apps).

### Why It Works:
- **Identity play** — "What would I look like as X?" is irresistibly clickable
- **Shareability** — People tag friends ("you'd make a great [character]")
- **Fandom crossover** — Taps into existing fan communities (anime, K-pop, Marvel)
- **Low effort, high reward** — Simple format, massive engagement

### Structure (6-10 seconds):
```
0-3s: Normal selfie + text ("Me normally" / "What I think I look like")
3-4s: Transition (spin, snap, hand-over-camera, flash)
4-10s: Transformed version (celebrity/character/fantasy)
Optional: Loop for rewatch
```

### Trending Audios:
- BalliBotMogis audio
- AI Dance Effect audios
- Character-specific songs (K-pop tracks for K-pop transformations)

### How to Adapt for Our Verticals:
| Vertical | Adaptation |
|----------|-----------|
| **AI Art Showcase** | "You → AI anime character" series |
| **Before/After** | Real face → AI stylized character |
| **Prompt Breakdown** | Show the prompt that created the transformation |
| **Model Reviews** | Same face swap across different AI tools (comparison) |
| **Trending Reactions** | "If [trending character] was me" reactions |

### Key Tools to Feature:
- KlingAI (dance + face swap)
- CapCut AI templates
- Midjourney character consistency
- Stable Diffusion IP-Adapter

## Format 3: "I Asked AI to..." Series

### What It Is:
A repeatable series format where the creator asks AI to do something specific, shows the prompt/input, then reveals the output. Educational + curiosity-driven.

### Why It Works:
- **Curiosity gap** — Title creates an open loop that demands closure
- **Educational value** — Viewers learn prompts, tools, techniques
- **Repeatable** — Infinite variations ("I asked AI to design my dream home/office/wardrobe")
- **Series potential** — Viewers follow for next episode
- **Comment generation** — "Ask AI to do X!" comments drive algorithm

### Structure (15-30 seconds):
```
0-3s: Hook text on screen ("I asked AI to design my dream workspace")
3-8s: Screen recording of typing prompt / selecting options
8-15s: AI output reveal (images, video, text)
15-20s: Reaction / commentary on results
20-30s: CTA ("Follow for more AI experiments")
```

### Trending Variations:
- "I asked AI to redesign [famous thing]"
- "I asked AI to create [impossible thing]"
- "I asked AI to combine [X] + [Y]"
- "I asked AI to predict [future thing]"

### How to Adapt for Our Verticals:
| Vertical | Adaptation |
|----------|-----------|
| **AI Art Showcase** | "I asked AI to create the most beautiful [theme]" |
| **Prompt Breakdown** | Show the exact prompt + settings used |
| **Model Reviews** | "I asked 5 AI models to draw the same thing" |
| **Trending Reactions** | "I asked AI to recreate [trending thing]" |
| **Before/After** | "I asked AI to fix my bad photo" |

## Format 4: "Algorithm Test" / Meta-Content

### What It Is:
A meta-format where creators test what the algorithm prefers — highly produced content vs quick AI-generated content. Self-referential and relatable to creators.

### Why It Works:
- **Relatability** — Every creator struggles with "what works"
- **Curiosity** — Viewers want to know which performs better
- **Authenticity signal** — Shows behind-the-scenes, not just polished output
- **Discussion driver** — Sparks debate in comments
- **Low production value = high trust** — Raw content feels more genuine

### Structure (10-20 seconds):
```
0-3s: "Seeing if the algorithm prefers..."
3-8s: Clip A (highly produced content — time-lapse, editing, effects)
8-10s: Transition / text ("OR")
10-15s: Clip B (quick AI-generated content — screen recording of prompt)
15-20s: Results / reaction / CTA to vote in comments
```

### How to Adapt for Our Verticals:
| Vertical | Adaptation |
|----------|-----------|
| **AI Art Showcase** | "Algorithm test: hand-drawn vs AI-generated" |
| **Prompt Breakdown** | "Simple prompt vs complex prompt — which does better?" |
| **Model Reviews** | "Cheap AI tool vs expensive one — algorithm doesn't care" |
| **Trending Reactions** | "Trending format vs original content — which wins?" |
| **Before/After** | "Before editing vs after AI enhancement" |

## Format 5: AI Dance Animation (Static → Dancing)

### What It Is:
A still, low-energy portrait or photo "comes to life" through AI animation — dancing, lip-syncing, or performing actions. Powered by KlingAI, CapCut MJ dance template, and similar tools.

### Why It Works:
- **Uncanny factor** — Still image moving is inherently attention-grabbing
- **Humor potential** — Funny to see static characters dance
- **Music synergy** — Pairs perfectly with trending songs
- **Shareability** — "I brought my photo to life" is highly shareable
- **Low barrier** — Anyone can do it with free tools

### Structure (6-12 seconds):
```
0-2s: Static portrait/photo + text ("I can't dance... or can I?")
2-3s: Beat hit + glitch/zoom transition
3-10s: AI-animated version dancing/singing
10-12s: Freeze frame or loop
```

### Trending Audios:
- Any trending dance song
- Billie Eilish "BIRDS OF A FEATHER"
- Jessie Murph "I Like How I Look"
- Classic meme songs

### How to Adapt for Our Verticals:
| Vertical | Adaptation |
|----------|-----------|
| **AI Art Showcase** | AI-generated character comes to life and dances |
| **Before/After** | Static AI art → animated AI art |
| **Prompt Breakdown** | "The prompt that made this character dance" |
| **Model Reviews** | Same animation across different AI video tools |
| **Trending Reactions** | Animate trending memes/characters |

## Cross-Format Strategy: How to Combine Formats

The most viral AI content often COMBINES multiple formats:

1. **"I asked AI to" + "Before/After"** → "I asked AI to glow up my selfie" (transformation + curiosity)
2. **"Algorithm Test" + "AI Dance"** → "Algorithm test: real dance vs AI dance"
3. **"Face Swap" + "Series"** → "Turning you into anime characters — Episode 1"
4. **"Glow Up" + "Education"** → "Summer glow up AI art — here's the exact prompt"

### Content Calendar Integration:
- **Monday:** "I asked AI to..." (educational series)
- **Tuesday:** Before/After transformation (showcase)
- **Wednesday:** Algorithm test (meta-content)
- **Thursday:** Face swap / character transformation (entertainment)
- **Friday:** AI dance animation (fun/trending)
- **Saturday:** Model review (comparison)
- **Sunday:** Trending reaction (timely)
