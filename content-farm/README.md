# 🌾 MAD Content Farm

## Overview

MAD Content Farm is a multi-platform AI content operation producing viral AI art content across TikTok, Instagram, X/Twitter, and Reddit. The farm uses a research-first, data-driven approach to content creation with diversified monetization.

## Directory Structure

```

├── coordination/              # Strategy, calendar, status

│   └── content-status.md      # Production tracking
├── templates/                 # Reusable templates
│   └── captions.md            # Caption templates + hook formulas
```
